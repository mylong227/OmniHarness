# 退出码契约（audit 子命令）

> 本文是 `omniharness audit` 三条路径（`export` / `report` / `verify`）退出码的**正式契约**，
> 由 `tests/unit/auditTool.test.ts` 的退出码判据锁死。改退出码语义必须同时改这里与判据。
> 失败原因 `reason` 的含义见 [ATTESTATION.md](ATTESTATION.md) §2。

---

## 1. 退出码

| 退出码 | 含义     | 触发条件（逐条）                                                                                                                                                                                                                                       |
| ------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `0`    | 全部成功 | `report`：所有报告生成并落盘（未指定 `--strict`，或所有输入的未识别条目为 0）；`verify`：所有报告链完整且自指纹对得上；`export`：导出成功（`--compliance` 时链完整或未启用）                                                                           |
| `1`    | 证据失败 | ① `verify`：任一报告复核失败（`reason` 见上表）；② `report --strict`：任一输入的 `unrecognized > 0`（报告**仍然生成**——先留证据再报失败）；③ `export --compliance`：审计日志链断裂；④ 输入不存在 / 读盘失败 / 格式认不出 / 超限（由 CLI 捕获打印原因） |
| `2`    | 用法错误 | 未知子命令 / 未知旗标 / 缺位置参数 / `--format` 或 `--source-format` 给了非法值                                                                                                                                                                        |

> 注：「多输入时 `--out` 指向单份报告路径」按 `Error` 抛出、CLI 捕获后归入 **1**（输入约束失败），
> 不归入 2；判据 `auditTool.test.ts` ②b 锁定此行为。

## 2. `--strict` 的精确语义

- 只作用于 `report`（含简写 `audit <file>`）：**任何**一个输入文件的 `unrecognized > 0` ⇒ 最终退出码 1；
- 报告照常逐份生成——strict 失败**不销毁证据**，stdout 会逐文件标注「未识别 N 条」；
- 与 `--source-format` 的交互：**强制指定格式不会降低 unrecognized 的计数口径**——强制成
  `codex` 后文件里该解析器仍认不出的条目照常计入 unrecognized（「格式是我指定的」不构成
  豁免）；strict 只看这个数，不看格式是否与自动识别一致；
- `verify` 没有 strict 形态：复核失败本来就是 1。

## 3. 判据对应

| 判据（`tests/unit/auditTool.test.ts`）               | 锁定的退出码行为                       |
| ---------------------------------------------------- | -------------------------------------- |
| ①⑤（report / CLI report / 用法错误）                 | 成功 0；未知旗标、缺参数、非法格式值 2 |
| ②b（多输入给单文件 out）                             | 输入约束失败 1（抛错路径）             |
| ③③b（篡改载荷 / 只改展示层）                         | verify 失败 1                          |
| ⑥（strict：漂移夹具 strict ⇒ 1，非 strict ⇒ 0）      | strict 语义                            |
| ⑦⑧（改 `coverage.recognized` / `summary.total` ⇒ 1） | verify 自洽对账                        |
