# 剩余阻塞项（2026-10-25）

> 目标已推进到本机可完成边界；以下是必须由**外部环境/凭据**才能继续的项，均附复现证据与
> 解阻后命令。

## 1. 代码签名与自动更新签名

- 现状：安装包 `signed:false`，`RELEASE_MANIFEST.json` 明确记录；只有 SHA256 完整性清单。
- 缺：发布证书（PFX/证书存储）与密码；没有证书不能生成可信签名。
- 解阻后：
  ```powershell
  signtool sign /f cert.pfx /p <password> /fd sha256 /tr <timestampUrl> /td sha256 "OmniHarness Setup 0.2.0.exe"
  ```
  或配置 electron-builder `win.certificateFile` / `CSC_LINK`。

## 2. 浏览器 W1/S2 真机

- 现状：app server 可起（`--mock`，临时 home），UI URL 可生成；
- Chrome 在本机受限 shell 下失败：
  ```text
  FATAL:mojo\public\cpp\platform\platform_channel.cc:112 Check failed: ... 拒绝访问
  crashpad OpenProcess: 拒绝访问
  ```
- Vitest/Vite：`spawn EPERM`（esbuild service）。
- 解阻后（普通 Windows 用户会话/CI）：
  ```bash
  npm run web:test
  # 打开 serve URL，DevTools Performance 看 omni.thread.firstPage
  ```

## 3. 真实长任务评测

- 缺 `OMNIHARNESS_API_KEY`（或对应厂商 key），且 `verify.mjs` 需要可 spawn 子进程。
- 解阻后：
  ```bash
  npm run build
  node tools/eval/longTasks.mjs --self-check
  node tools/eval/longTasks.mjs --k 3 --model <model> --out report.json
  ```

## 4. 安装包静默安装冒烟

- 现状：安装包结构/压缩/SHA256 已校验；本机 `Start-Process /S` 未返回可验证结果。
- 解阻后：普通 Windows 用户会话运行安装器 `/S`，检查
  `%LOCALAPPDATA%\Programs\OmniHarness\OmniHarness.exe` 与卸载。

## 5. Skill 运行时工具级锁

- 现状：激活期 `resources`/`exclusive` 互斥 + 多会话文件锁/公平 shell 闸门（§102）；
- 未做：跨工具的进程级资源锁（需给工具声明资源域与锁语义），属功能设计而非环境阻塞。
