## 0. 一句话

**选择器从「逐级走进文件系统的迷你资源管理器」升级为「站在工作区之上的文件空间」**：
树是常驻的空间 context，工作区文件一次 RPC 整棵可得、可即时过滤、可跨目录多选；
工作区之外（盘符/任意路径）才退回按需懒加载的浏览模式。

## 1. 现状与问题（为什么重设计）

| #   | 现状                                        | 代价                                                                                             |
| --- | ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1   | 进入子目录 = 整列表替换（导航隐喻）         | 层级上下文丢失：不知道自己在哪、跳同级要 `..` 数步                                               |
| 2   | 跨目录多选被禁止（导航即清空选择）          | 附件常散在多个目录 ⇒ 多轮往返                                                                    |
| 3   | 每进一层一次 `fs.browse` RPC + 全局代际守卫 | 慢盘上「代际防串」复杂度全由扁平模型制造                                                         |
| 4   | 无搜索                                      | 只能肉眼逐层找；而**工作区文件树侧栏早就是一次 `fs.list` 的整棵 antd Tree** —— 选择器反而 weaker |

## 2. 数据地基（已核实的事实，设计不悬空）

- **`fs.list(depth)` RPC 已存在**（`ApiClient.listFs`）：一次返回整棵工作区树
  `FsNode { name, path, type: 'file'|'dir', children? }`；侧栏 `FileTree.tsx` 已把它映射成
  antd Tree treeData 并经真机验证。**工作区模式零新增后端接口**。
- `fs.browse(path, includeFiles)` 保留：**工作区之外**（盘符 / 用户目录 / 任意绝对路径）的
  按层懒加载仍然用它——它是唯一能列出「此电脑」层级的接口。
- 无文件名搜索 RPC ⇒ 工作区内的搜索 = **已加载树上的客户端过滤**（树在内存里，过滤是即时的）。

## 3. 设计思路（三条纲领）

1. **空间隐喻替代导航隐喻**：树常驻，进入目录不再是「换一屏」而是「展开一个节点」——
   你始终看得见自己在哪、邻居是谁、家在哪。
2. **双源供给**：工作区内 = `fs.list` 整棵树（快、可过滤、无守卫）；工作区外 = `fs.browse`
   节点级懒加载（`Tree.loadData`）。两条数据通路在视觉上是**同一棵树**（工作区根节点之下
   挂「文件系统…」入口），用户不需要理解两套模型。
3. **选择即路径**：树节点天然携带绝对路径 ⇒ 跨目录多选不再是「被禁止的功能」而是树模型的
   顺产；选中集就是「勾选的文件节点集合」，页脚实时给**数量 + 总体积**（附件体积预算感知）。

## 4. 信息架构与界面

### 4.1 FilePicker（附件多选）—— 双栏

```
┌─ 选择附件文件 ──────────────────────────────────────────┐
│ [ 🔍 过滤已加载的树…                    ]  [ 刷新 ] [ 路径: /工作区/src ] │
│ ┌───────────────────────────────┬──────────────────────┐ │
│ │ ▾ 🗀 new_work_0000001         │  已选 2 个 · 共 84 KB  │ │
│ │   ├ ☑ pelican-bike.html 405K  │ ┌──────────────────┐ │ │
│ │   ├ ☐ main.ts         12K     │ │  (选中文件预览：   │ │ │
│ │   ├ ▸ 🗀 backend              │ │   文本前 40 行 /   │ │ │
│ │   └ ▸ 🗀 frontend             │ │   图片缩略 /       │ │ │
│ │ ▸ 🗀 文件系统…                 │ │   二进制说明)      │ │ │
│ └───────────────────────────────┴──────────────────────┘ │
│                                       [ 取消 ] [ 添加 2 个文件 ] │
└─────────────────────────────────────────────────────────┘
```

- **左：antd Tree（`checkable` + 虚拟滚动 `height`）**。文件节点 = 叶子 + 复选框；目录节点 =
  展开/收起（工作区树已整棵在内存，展开是纯客户端；「文件系统…」子树走 `loadData` 懒加载）。
- **右：选中预览窗格**（新增价值，P3 可后置）：单选高亮即预览——文本读 `fs.read` 前 40 行、
  图片给缩略、二进制只报体积/类型。多选时列出清单。**这是扁平浏览器给不了的能力**。
- **顶栏**：过滤框（客户端过滤已加载树，IME 组合期语义沿用 PickerKeys 的 isComposing 纪律）；
  路径徽标（当前工作区根）；刷新按钮（重拉 `fs.list`，展开态与勾选保留）。
- **页脚**：取消 / 添加 N 个文件（含总体积）——确认语义不变，回传绝对路径数组。

### 4.2 FolderPicker（目录单选）—— 单树

- 同一棵树的**无复选框**形态：目录节点高亮 + 底部「选择当前目录」显式确认（单击 = 展开/
  收起，遵循树的习惯；Enter = 选定高亮节点）；不支持文件节点（type==='file' 置灰不可选）。
- 默认定位到当前工作区根并展开一层。

### 4.3 「文件系统…」懒加载子树（两种选择器共用）

- 节点：`此电脑（盘符）` → 各盘 → 目录链。展开一个目录节点 = 一次 `fs.browse(path)`，
  结果填充该节点的 children（`Tree.loadData`）。
- **代际守卫语义随之简化**：从「全局代际号防整列表串台」变为「**节点级**填充」——
  每次展开是独立异步任务，慢盘上 A 节点的迟到响应只会迟到地填 A 节点，不可能影响 B
  （结构性消除 staleResponseGuards 防的那类串台，判据改为节点级断言）。
- 错误态挂在节点上（⚠ + 重试），不弹全局错误。

## 5. 交互与键盘模型

| 键     | 行为                                                   | 出处                        |
| ------ | ------------------------------------------------------ | --------------------------- |
| ↑/↓    | 树内活动节点移动（antd 内建）                          | antd Tree                   |
| →/←    | 展开 / 收起（工作区节点纯客户端；懒节点触发 loadData） | antd Tree                   |
| Enter  | 文件：勾选/取消勾选；目录：展开/收起                   | antd Tree（checkable 语义） |
| Space  | 同 Enter（勾选）                                       | antd Tree                   |
| Ctrl+F | 焦点进过滤框                                           | 新增                        |
| Esc    | 关闭弹窗，焦点归还触发器                               | PickerModal 既有契约        |
| Tab    | 过滤框 ↔ 树 ↔ 页脚按钮（Modal 焦点陷阱内）             | 既有                        |

- **删除的自研机制**（被 antd 内建取代）：逐项 `tabIndex=0` + ActivationKeys 的逐条 Enter、
  roving tabindex 手工维护——**Tree 的 role=tree/treeitem + 内建键盘即 WAI-ARIA 标准形态**。
- **保留的自研机制**：过滤框 IME 组合期放行（PickerKeys.isComposing 纪律）、Esc 归还焦点、
  确认按钮的禁用条件（0 选择禁用）。
- 目录「展开即选中」不混用：**勾选只发生在文件**（FolderPicker 例外见 4.2）——杜绝
  「勾了目录算不算递归选中」的语义泥潭（v1 明确：不递归；需要整个目录时将来可加
  「勾选目录内全部」作为显式节点动作，不做隐式递归）。

## 6. 状态机

| 态                 | 表现                                                                     |
| ------------------ | ------------------------------------------------------------------------ |
| 首开装载           | 树骨架骨架屏（antd Skeleton 两层），过滤框可用                           |
| fs.list 失败       | 树位置给错误 + 重试（工作区树失败不挡「文件系统…」懒加载模式）           |
| 空工作区           | 树给空态（EmptyState：工作区没有文件——去 composer 发任务生成）           |
| 空目录（懒节点）   | 节点展开后显示「（空目录）」子行                                         |
| 拒绝授权（懒节点） | 节点 ⚠ + 单节点重试                                                      |
| 大树               | `Tree height` 虚拟滚动；`fs.list` 深度默认 3、可调；超深目录靠懒加载续接 |
| 刷新               | 重拉 fs.list，保留展开键集与勾选集（path 为键，天然稳定）                |

## 7. 视觉规格（纸与墨 × antd Tree）

- 节点密度 28px（与 antd 密度口径一致）；目录 🗀 / 文件按 `FileIconResolver.mediaType` 出图标；
  文件尺寸右对齐 11px `--dim`；勾选行底色 `--ant-color-primary-bg`（语义来自 antd token，
  不自造色值——DESIGN_SYSTEM v2 纪律）。
- 树容器透明底 + 发丝线（面板表格同口径）；预览窗格与树之间 `--hairline` 分隔。
- 预览窗格文本 12px mono（复用 CodeSurface 的只读形态，不新做高亮管线）。

## 10. 风险登记

| 风险                           | 缓解                                                                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 超大仓库 `fs.list` 体积        | depth 默认 3 + 超深懒加载续接；树虚拟滚动；必要时后端加 ignore 规则复用                                                  |
| rc-tree 键盘与 IME 冲突        | 过滤框独占输入（组合期放行既有纪律）；树本身不接文字输入                                                                 |
| 双源状态混杂                   | 工作区子树与「文件系统…」子树以 key 前缀隔离（`ws:` / `fs:`），勾选集只收 `fs:` 之外的工作区文件与懒加载确认过的绝对路径 |
| 侧栏 FileTree 与选择器行为漂移 | 共用 `FsNode→TreeDataNode` 映射与图标解析；不共用组件实例（数据形态契约对齐即可）                                        |
