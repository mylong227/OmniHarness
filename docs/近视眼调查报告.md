# 近视眼（Myopia）调查报告

> 报告类型：文献综述型调查（Desk Research / Literature Review）
> 版本：v1.0　状态：初稿，待补充一手数据
> 说明：本报告基于公开流行病学数据、meta 分析、随机对照试验（RCT）与我国政策文件整理。全球与中国的流行病学数字受样本、年龄口径、验光方式（自报 vs 小瞳/散瞳验光）影响差异较大，凡涉具体数字均标注来源与不确定性，不宜直接用于临床诊断或投资决策。

---

## 一、摘要（核心结论）

1. **近视已成为全球性公共卫生问题**。全球近视患病率约在 20 年间从 ~23% 上升到 ~30% 量级，权威模型的预测是 2050 年接近全球人口的一半；其中高度近视（可致盲风险显著升高）的增长速度更值得警惕。
2. **东亚（尤其中国、韩国、新加坡、日本）是全球近视负担最重的地区**。我国儿童青少年总体近视率在 2018 年国家大规模调查中为 **53.6%**，高中阶段超过 **80%**，呈"高发、低龄化、重度化"特征。
3. **病因是"遗传易感性 + 环境暴露"共同作用**。遗传决定谁更容易近视，环境（高强度近距离用眼、户外光照不足）决定近视是否发生、进展多快。**户外活动时间不足是目前证据最强、可干预的环境因素。**
4. **近视不只是"配副眼镜"的问题**。高度近视（约 ≤ -6.00 D 或眼轴 ≥ 26.5 mm）伴随视网膜脱离、近视性黄斑病变、青光眼、白内障风险显著上升，是东亚地区不可逆性视力损害的主要原因之一。
5. **有效的防控手段已具备，但各有边界**：户外活动（预防，证据强）、低浓度阿托品（延缓，证据强）、周边离焦光学矫正（OK 镜 / 离焦框架镜 / 多焦点软镜，延缓，证据中等偏强）。**没有任何单一手段能"治愈"近视**，联合治疗与全程管理是共识方向。
6. **最大缺口**：缺乏高质量、长期、中国本土的疗效与安全性真实世界数据；基层筛查—转诊—干预链条不完整；家长与学校对"近视不可逆、重在延缓"的认知仍需提升。

## 二、定义与分类

### 2.1 定义

近视（myopia）指在调节放松状态下，平行光线经眼球屈光系统后聚焦于视网膜**前方**，导致远视力下降、近视力相对正常的屈光不正状态。

- **等效球镜度（SE）**：球镜度 + 1/2 柱镜度；SE ≤ -0.50 D 通常作为近视判定阈值。
- **眼轴长度（AL）**：与近视程度高度相关。新生儿约 16.5–17 mm，3 岁约 22.5 mm，成人正视约 24 mm。眼轴每增长 1 mm，屈光度约向近视方向变化 2.5–3.0 D。
- **近视前期（pre-myopia）**：屈光度介于 -0.50 D 与 +0.75 D 之间且伴高风险因素，是干预的关键窗口期。

### 2.2 分类

| 维度       | 类型                                                        | 临床含义                               |
| ---------- | ----------------------------------------------------------- | -------------------------------------- |
| 发病机制   | 轴性近视 / 屈光性近视                                       | 轴性以眼轴过长为主，占绝大多数         |
| 病程与病理 | 单纯性近视 / 病理性近视（PM）                               | 病理性近视伴眼底退行性改变，致盲风险高 |
| 屈光度     | 低度（≤ -3.00 D）/ 中度（-3.00~-6.00 D）/ 高度（> -6.00 D） | 高度近视并发症风险陡增                 |
| 发病年龄   | 先天性 / 早发性（<6 岁）/ 学龄期 / 成年期                   | 发病越早，成年后高度近视概率越高       |
| 特殊类型   | 假性近视（调节痉挛）/ 继发性近视                            | 假性近视可通过散瞳验光鉴别，不应误判   |

> **关键点**：假性近视与真性近视的鉴别必须依赖**睫状肌麻痹（散瞳）验光**。基层用电脑验光仪直接出度数，是导致"过矫"与误判的主要来源。

## 三、流行病学调查

### 3.1 全球

- **患病率与预测**：Holden 等（2016, _Ophthalmology_）基于全球人群数据估计，2000 年全球近视患病率约 **22.9%（约 14.1 亿人）**，2050 年预计升至约 **49.8%（约 47.6 亿人）**；高度近视从 2000 年约 **2.7%（1.63 亿人）**升至 2050 年约 **9.8%（9.38 亿人）**。
- **地区差异**：东亚城市地区成年人群近视率普遍 > 80%，而非洲部分地区、农村地区仍在 10% 以下。差异之大说明环境因素（教育强度、户外时间）作用突出，而非单纯种族遗传。
- **WHO 视角**：近视已被列入全球视觉健康优先议题，未矫正屈光不正长期是"可避免性视力损害"的首位原因。

> ⚠️ 数据口径提醒：不同研究对"近视"的判定（自报 / 裸眼视力 / 非散瞳验光 / 散瞳验光）、年龄下限与城乡抽样方式差异，可造成 5–15 个百分点的偏差。跨国比较需谨慎。

### 3.2 中国

**官方筛查数据（国家卫健委 / 教育部）**

| 年份 | 儿童青少年总体近视率 | 备注                                           |
| ---- | -------------------- | ---------------------------------------------- |
| 2018 | **53.6%**            | 覆盖千余所学校、逾百万学生的全国调查，为基准年 |
| 2019 | ~50.2%               | 较 2018 年有所下降                             |
| 2020 | ~52.7%               | 疫情居家线上学习期间反弹                       |
| 2021 | ~52.6%               | 高位波动                                       |
| 2022 | ~51.9%               | 高位波动                                       |

> 上述 2019–2022 数字为公开报道口径，统计范围与抽样方法逐年略有调整，趋势判断（高位波动、未达"每年降 0.5 个百分点"目标）比单点数值更可靠。

**2018 年分学段近视率**

| 学段     | 近视率 |
| -------- | ------ |
| 6 岁儿童 | 14.5%  |
| 小学     | 36.0%  |
| 初中     | 71.6%  |
| 高中     | 81.0%  |

**结构性特征**

1. **低龄化**：6 岁儿童近视率已达两位数，意味着近视在入学前就已发生，干预窗口被前移。
2. **重度化**：高中阶段高度近视比例明显上升，成年后病理性近视风险随之抬升。
3. **性别差异**：多数调查显示女生近视率略高于男生（可能与户外活动时间、用眼习惯差异有关），但差异幅度远小于学段差异。
4. **城乡差异**：历史上城市高于农村，近年来**农村地区近视率上升更快**，城乡差距收窄，可能与电子设备普及、教育内卷扩散有关。
5. **疫情效应（COVID-19）**：多项研究提示 2020 年居家隔离与线上教学期间，学龄儿童近视发生率与新发率显著上升，尤其低龄段更敏感。相关研究结论方向一致，但具体幅度因研究设计差异较大。

## 四、发病机制与危险因素

### 4.1 机制假说（当前主流认识）

| 假说                      | 核心内容                                                              | 证据地位                             |
| ------------------------- | --------------------------------------------------------------------- | ------------------------------------ |
| **遗传易感性**            | 父母近视（尤其双方高度近视）显著提升子女风险；GWAS 已定位大量易感位点 | 证据强（但非充分条件）               |
| **户外光照 / 多巴胺假说** | 强光照促进视网膜多巴胺释放，抑制眼轴增长                              | 证据较强，可解释户外保护效应         |
| **调节滞后与近距离用眼**  | 持续近距离用眼产生调节滞后，形成远视性离焦刺激                        | 证据中等，机制仍有争议               |
| **周边离焦理论**          | 周边视网膜远视性离焦是驱动眼轴增长的关键信号                          | 证据较强，是离焦镜片/OK 镜的理论基础 |
| **巩膜重塑与生物力学**    | 巩膜变薄、细胞外基质降解，眼轴在眼压下被动扩张                        | 证据中等，属下游共同通路             |
| **视黄酸等信号分子**      | 视网膜—脉络膜—巩膜间存在调控眼轴生长的信号级联                        | 基础研究阶段                         |

**综合理解**：遗传决定"阈值高低"，环境决定"是否触发"。眼轴增长是眼球对"视觉环境错配"（近处清晰、周边离焦、光照不足）的代偿性发育结果，且**一旦眼轴增长难以回退**，故称"近视不可逆"。

### 4.2 危险因素与保护因素

**危险因素**

- 父母近视，尤其双方高度近视（家族聚集性显著）
- 每日户外活动时间不足（< 2 小时）
- 持续近距离用眼时间过长、读写距离过近（< 30 cm）
- 照明不足 / 过强、频闪、眩光；电子屏幕使用时间过长且距离过近
- 睡眠不足、作息紊乱（部分研究提示关联）
- 高强度学业压力与教育竞争（群体层面最重要）
- 低龄即出现远视储备不足（关键预警指标）

**保护因素**

- 每日 ≥ 2 小时户外活动（或每周 ≥ 14 小时）
- 良好的读写姿势（"一尺一拳一寸"）、每 30–40 分钟远眺休息
- 充足、均匀的室内照明与合适的读写台灯
- 定期视力与屈光发育监测、建立屈光档案

> **剂量—反应关系**：多项研究提示户外活动时间与近视风险存在剂量关系（例如每周户外时间每增加 1 小时，近视风险有数个百分点量级的下降）。广州一项整群 RCT 通过在课间增加约 40 分钟/天户外时间，使 3 年累积近视发生率出现有统计学意义的下降（相对风险约 0.77 量级）。**注意：户外活动对"预防新发"证据较强，对"已近视者延缓进展"证据较弱。**

## 五、并发症与危害

### 5.1 临床并发症（主要风险集中在高度/病理性近视）

| 并发症                             | 风险特征                                           | 后果                                   |
| ---------------------------------- | -------------------------------------------------- | -------------------------------------- |
| 视网膜裂孔 / 视网膜脱离            | 高度近视风险显著升高（量级上约为普通人群的 10 倍） | 急症，延误可致永久性视力丧失           |
| 近视性黄斑病变（MMD）              | 眼轴越长风险越高，随年龄累积                       | 东亚地区不可逆性视力损害的主要原因之一 |
| 青光眼（开角型）                   | 风险约为普通人群 2 倍                              | 隐匿进展，视野不可逆缺损               |
| 白内障（核性 / 后囊下）            | 风险升高，且发病年龄提前                           | 可通过手术改善，但高度近视手术风险更高 |
| 玻璃体混浊、黄斑劈裂、后巩膜葡萄肿 | 高度近视常见                                       | 视功能与生活质量下降                   |

> **风险阈值提示**：当 SE ≤ -6.00 D 或眼轴 ≥ 26.5 mm 时，应纳入"眼底随访管理"，建议定期散瞳查眼底。

### 5.2 非临床危害

- **功能与生活质量**：运动受限（尤其对抗性运动、潜水）、职业选择受限（部分军警、飞行岗位有裸眼视力要求）、心理与社交影响（青少年近视与焦虑、自尊相关）。
- **经济负担**：直接成本包括验光配镜、角膜接触镜、OK 镜、药物、手术；间接成本包括生产力损失。有国际研究估算，未矫正近视造成的全球年度生产力损失在数百亿美元至两千余亿美元量级，且以亚太地区占比最高。**中国尚缺乏权威、连续的全社会成本核算。**
- **公共卫生系统压力**：高度近视人群基数大，意味着未来数十年眼底病诊疗需求将持续攀升（存在"发病—致盲"的滞后效应）。

## 六、干预措施与证据强度

| 干预手段                           | 作用定位            | 大致效果（文献量级）                                                           | 主要局限                                                           | 证据强度             |
| ---------------------------------- | ------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------ | -------------------- |
| **增加户外活动**                   | 预防新发（首选）    | 每周户外多 1 小时，风险有数个百分点量级下降；干预性研究相对风险约 0.8 量级     | 对已近视者延缓进展效果有限；执行依从性差                           | 强                   |
| **低浓度阿托品（0.01%–0.05%）**    | 延缓进展            | 可显著减缓屈光度与眼轴进展；浓度越高效果越强，但畏光、视近模糊、停药反弹越明显 | 需医生处方与随访；国内可及性与合规使用受限                         | 强                   |
| **角膜塑形镜（OK 镜）**            | 延缓进展 + 白天脱镜 | 多数研究显示 2 年可减少约 0.1–0.2 mm 眼轴增长；个别高质量 RCT 未显示显著差异   | 护理要求高、感染性角膜炎风险（罕见但严重）、费用高                 | 中等                 |
| **周边离焦框架镜（DIMS/HALT 等）** | 延缓进展            | 2 年近视进展相对减少约 60% 量级                                                | 镜片价格高；外观与依从性                                           | 中等偏强             |
| **多焦点软性接触镜（如 MiSight）** | 延缓进展            | 3 年 RCT 显示屈光度进展相对减少约 50%–60% 量级                                 | 接触镜相关风险、费用、依从性                                       | 中等偏强             |
| **双光镜 / 渐进多焦镜**            | 延缓进展            | 效果小且不一致                                                                 | 对眼轴影响有限                                                     | 弱—中等              |
| **重复低强度红光（RLRL）**         | 延缓进展            | 部分研究报告效果积极                                                           | **安全性证据不足**，已有视网膜光损伤相关不良反应报告，监管态度趋严 | 弱（且存安全性争议） |
| **联合治疗（阿托品 + 光学离焦）**  | 延缓进展            | 部分研究提示优于单一手段                                                       | 方案标准化不足、长期安全性数据有限                                 | 中等                 |
| **屈光手术（LASIK/SMILE/ICL）**    | 矫正（非治疗）      | 术后裸眼视力良好                                                               | **不能改变眼轴与眼底并发症风险**；须成年、度数稳定                 | 强（作为矫正手段）   |
| **巩膜交联等实验性手段**           | 延缓进展            | 早期探索                                                                       | 尚在临床研究阶段                                                   | 弱                   |

**处方决策的常识**：

- 未近视但远视储备不足 → 优先行为干预（户外、用眼习惯）+ 密切监测；
- 已近视低龄儿童（尤其 < 10 岁、进展快）→ 应尽早考虑光学离焦或低浓度阿托品等主动干预；
- 高度近视 → 重点从"控度数"转向"防并发症"，建立眼底随访。

## 七、政策与公共卫生应对（中国）

1. **《综合防控儿童青少年近视实施方案》（2018 年 8 月，教育部等八部门）**
   - 目标：到 2023 年，力争全国儿童青少年总体近视率在 2018 年基础上**每年降低 0.5 个百分点以上**，近视高发省份**每年降低 1 个百分点以上**。
   - 到 2030 年：**6 岁儿童近视率控制在 3% 左右，小学生下降到 38% 以下，初中生下降到 60% 以下，高中生下降到 70% 以下**。
2. **《儿童青少年近视防控光明行动工作方案（2021—2025 年）》**：将"减轻学业负担、强化户外活动、改善视觉环境、加强筛查建档"等列为重点任务。
3. **落地机制**：学校每年视力筛查与屈光档案、教室照明与课桌椅改造、"双减"政策对课外培训与作业量的约束、近视防控纳入地方考核。
4. **落实中的主要挑战**
   - 筛查质量参差（设备、人员、是否散瞳），数据可靠性不足；
   - "筛查—转诊—干预—复诊"闭环不完整，检出后家长不重视或过度焦虑并存；
   - 学业竞争的结构性压力未被真正缓解，行为干预难以持续；
   - 干预手段的可及性、价格与规范化使用（如低浓度阿托品配制、OK 镜验配资质）不均衡。

> **政策目标与现实的距离**：以 2018 年 53.6% 为基线，若实现"每年降 0.5 个百分点"，到 2023 年应接近 51% 量级。公开数据显示实际呈**高位波动**，说明行为与环境层面的干预强度尚不足以对冲学业压力与电子屏幕暴露的增长。

## 八、争议与证据空白

1. **户外活动保护效应的机制**：是光强/多巴胺主导，还是"替代近距离用眼"的时间置换效应？影响干预设计。
2. **低浓度阿托品用于"预防"（尚未近视者）**：部分高质量 RCT 未显示可显著降低近视发生率，其定位更可能是"延缓"而非"预防"。
3. **OK 镜疗效**：亚洲研究多为积极结果，个别西方高质量 RCT 未显示显著差异，存在人群与设计差异。
4. **红光治疗（RLRL）**：疗效报告与安全性担忧并存，缺乏独立、长期、多中心的安全数据，监管态度趋严，不推荐作为常规首选。
5. **遗传—环境交互**：GWAS 位点的预测效能有限，尚无法用于个体化风险预测。
6. **数据缺口**：中国缺乏覆盖全年龄段、连续多年、统一口径的近视与眼轴队列数据；成人高度近视并发症的自然史与经济负担核算亦不足。

## 九、建议

### 9.1 对儿童青少年

- 每天保证 **≥ 2 小时**户外时间（累计即可，不要求连续），课间走出教室；
- 读写时保持"一尺一拳一寸"，每 30–40 分钟远眺放松 5–10 分钟；
- 减少非学习目的的近距离屏幕时间，屏幕越大、距离越远越好；
- 保证充足睡眠。

### 9.2 对家长

- **3 岁起**建立屈光发育档案，每 6–12 个月复查视力、屈光度与眼轴；
- 关键预警：**远视储备低于同龄正常值**——这比"已经近视"更早、更值得干预；
- 不接受非散瞳验光直接配镜，警惕"治愈近视""降低度数""摘掉眼镜"类宣传；
- 一旦确诊，重点是**延缓进展、避免高度近视**，而非拒绝配镜。

### 9.3 对学校与教育系统

- 保障每天校内户外活动与体育课时长，落实课间"离座远眺"；
- 改善教室照明、黑板与投影对比度、课桌椅与身高匹配度；
- 规范视力筛查流程，统一设备与判定口径，筛查结果真实反馈家长并跟踪复诊。

### 9.4 对医疗机构与公共卫生部门

- 推动"筛查—转诊—干预—随访"闭环与分级诊疗；
- 加强基层散瞳验光与眼轴测量能力建设；
- 建立区域近视与眼轴登记数据库，支撑真实世界疗效与安全性评价；
- 对高度近视人群建立规范眼底随访路径。

### 9.5 对政策制定者

- 将防控指标从"近视率"扩展到"眼轴增长速度"与"高度近视占比"等更敏感的中间指标；
- 对低浓度阿托品、OK 镜、红光治疗等干预手段建立统一的**有效性与安全性评价规范**与不良反应上报机制；
- 对已证实有效的行为干预（户外时间）给出制度性保障，而非仅停留在倡导。
