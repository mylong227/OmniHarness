**收紧触发项（均真实证据）**：

- `symmetryBreaking.threshold` TIGHTEN：self-driven instability=1.000（阈值附近振荡 32/64）；生产路径 instability=0.000 → KEEP（负载未触发）。
- `heatAnnealer.resonanceThreshold` TIGHTEN：production driftStd=7.031（退火剧烈抖动）；self-driven driftStd=0.250 → KEEP（稳定性 KPI 揭示不同负载状态）。**按 A 决议暂不动用（维持 0.60，不向 0.9 收紧）**：drift 长尾为事实高速涌入的负载固有特征，高 drift 在持续注入新事实时恰是退火器正常适应（记忆场在学新事实），把"高 drift"当缺陷消除等于把退火器干活当 bug。
- **诚实修订（phantom 旋钮）**：原 `skillComposer.twistThetaDeg` TIGHTEN 经代码复核为**假收紧**——引擎 `composeByTwist` 仅消费 `min/max/step` 扫描区间，无单一扭转角旋钮。真实涌现旋钮已改为 `capabilityCrystallizer.emergenceFloor` 并接入 `composeByTwist`+固化器报告+spark 发射，生产路径实测 21 个真实涌现样本（mean=0.307，≥0.3 → KEEP），证明接线真实有效、非伪造。

## 5. 诚实边界总览

1. **外部 LLM 真实流量（原留白，本轮已闭合）**：成文时所有"production"观测均由 `ScriptedModel`（确定性 replay）驱动**真实 Agent 主循环**经生产同源装配路径产生，负载来源透明声明、累积链路与真实部署一致；**2026-09-03 末已用真实 DeepSeek `deepseek-chat` 经 `longrun_prod_real.mjs`（`npm run longrun:prod:real`）端到端验证闭合**——累积 21 条 production 观测、哈希链 ok=true、实花 $0.0003（远低于 $0.50 护栏），七引擎各发射 3 次可见真实涌现（crystallizer.emergences≈0.38–0.40）/ 对称破缺（orderParameter=1, state=broken）/ 禁闭（裸能力结构性拒配）。持续累积只需换入真实 LLM key。
2. **自检=代表性探针**：六属性自检与单测是"真实已落地算子端到端验证 + 单测证据聚合"，非穷举压力测试；RSI 红线是看板锁定项、非靠代码绕过。
3. **长期运行=工程基座已就位**：遥测/哈希链/闭环协议真实可用、已用两类真实负载跑通；"持续累积外部流量"是部署侧动作，非本工程缺项。
4. **零依赖/零回归**：全程未引入任何外部包，全量单测零回归（仅 benchmark 与文档新增）。
