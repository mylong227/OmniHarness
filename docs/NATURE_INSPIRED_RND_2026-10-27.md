## 1. 间隔效应（Spacing Effect）：Ebbinghaus 遗忘曲线 + 间隔重复 → 长期记忆召回

**状态：已落地（默认关），判据 7 例；增益验证按下方预注册规则执行。**

### 1.1 机制来源（心理学/生物学）

- Ebbinghaus (1885)：记忆保持率随时间**指数衰减** `R(t) = 0.5^(t/S)`，S 为稳定度。
- 间隔重复（SuperMemo-2 → FSRS 一系）两条可迁移结论：
  1. **合意困难**：在接近遗忘（低 R）时成功回忆一次，稳定度增益最大；
  2. **稳定度个体化**：重要内容衰减更慢；被反复回忆的内容越来越抗遗忘。

### 1.2 映射（机制级，不是比喻）

| 生物学概念           | 本仓对应物                                                              |
| -------------------- | ----------------------------------------------------------------------- |
| 记忆痕迹保持率 R(t)  | 召回排序因子 `retention(now, lastRecallAt ?? createdAt, S)`             |
| 稳定度 S（个体差异） | 每条事实 `stabilityDays`，初值 `30 × importance` 天                     |
| 一次成功回忆         | `recall(query,k)` 命中 top-k 且距上次强化 > 60 s                        |
| 强化（突触增益）     | `S' = S × (1 + (1-R))`，上限 10 年；`lastRecallAt=now`、`recallCount+1` |
| 遗忘                 | 不删除——R 衰减自然把旧事实压到排序尾部（`expiresAt` 仍是硬失效口径）    |

- 实现：`src/adapters/memory/spacingEffect.ts`（纯函数）+
  `fileLongTermMemory.recall` 的排序分支（`OMNI_MEMORY_FORGETTING=1` 开启）。
- 开启前行为：全局统一半衰期 90 天、不写新字段——**关闭时逐位等于旧行为**（判据钉住）。
- 与既有 `memoryAnnealing`（热方程扩散重加权）正交：退火改"共振簇共识"，本项改"单条时间动力学"。

### 1.3 判据（确定性注入时钟，`tests/unit/spacingEffect.test.ts`）

纯函数层：S0 锚点（importance 3 ⇒ 90 天，与旧全局半衰期同锚）、R 单调递减、
强化增益随 R 降低而增大（合意困难方向性）、S 上限封顶。
集成层：同分双事实，最近被召回者排前（保持率主导）；召回后稳定度写回且第二日起
排序反超（间隔重复闭环）；**默认关**时排序与旧实现逐位一致、不写任何新字段。

### 1.4 预注册的增益验证规则（满足才允许默认开启）

1. 语料：`tools/probes/recallHitrate` 现有语料 + 时间扰动（对每条 query 的相关事实
   随机指定 createdAt/lastRecallAt 分布，确定性种子）；
2. 对照：`OMNI_MEMORY_FORGETTING=0` vs `=1`，各跑 ≥ 5 轮，报 recall@k 与 MRR；
3. 判定：**配对 bootstrap 95% CI 下界 > 0**（沿 §1b 检索质量基线的口径）才提案默认开启；
4. 未达标 ⇒ 保持默认关，本文件登记"机制可用、增益未证"，与 Wave E 同款纪律。

### 1.5 诚实边界

- 机制级实现，不是 FSRS 完整拟合（无 w 系数向量/多级间隔/失败召回回退）；
- 判据证明数学性质与排序效果，**不**证明端到端任务成功率提升；
- 语料仍是本仓自建 fixture，不能外推为生产增益数字（对外材料引用须带此边界）。
