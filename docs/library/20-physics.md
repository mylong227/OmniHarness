## 1. 统计力学：为什么 Softmax 就是 Gibbs 分布

```
配分函数:      Z = Σ_x exp(−β E(x)),   β = 1/(k_B T)（T 为温度）
Gibbs/Boltzmann: p(x) = exp(−β E(x)) / Z
自由能:        F = E − T S        （能量与熵的权衡）
最大熵原理:    在约束 E 固定的条件下，使 S 最大的分布就是 Gibbs 分布
```

**关键联系（可直接用）**：

```
softmax(z)_i = exp(z_i / τ) / Σ_j exp(z_j / τ)
```

**Softmax 就是 τ 为温度的 Gibbs 分布**（$z = -E$）。因此：

> **本仓库推论（高价值）**：
> ① 采样温度 $\tau$ 与物理温度是同一件事。把「采样温度」和「退火温度」当成两个独立旋钮是**概念冗余**——它们应当共享一条调度曲线。
> ② `genesis/regime.ts` 用**香农熵**（`H = −Σ p ln p`，取 $k_B=1$）度量模态混乱度，与 $F = E - TS$ 中的 $S$ 一致；因此「高熵 ⇒ 触发 fuse」在物理上就是**「高温 ⇒ 更无序 ⇒ 需降温/合并」**。这条链条是**自洽的**（L1）。
> ③ **可操作**：`prune` 的触发条件是「成本压力 > 0.7」，这是**硬阈值（L0 风格）**。若要升到 L2/L3，应换成**接受概率形式** `min(1, exp(−ΔE/T))`，让「压力」与「温度」在同一个方程里——这样才真正与退火同构。

## 2. 第二定律与耗散结构：OmniHarness 是什么类型的系统

```
第二定律（孤立系统）:   ΔS_total ≥ 0
耗散结构（Prigogine）: 开放系统远离平衡态时，通过持续耗散
                        在局部维持低熵有序结构（ΔS_local < 0 由外部补偿）
熵产生率:               σ = Σ J_k X_k ≥ 0  （通量 × 力）
```

**判定（本馆）**：

> OmniHarness 是**有界开放耗散系统**：
>
> - 它持续**注入**资源（token / 算力 / 电），
> - 持续**排出**熵（产生的日志、轨迹、预算消耗），
> - 以维持一个**局部低熵有序态**（可用上下文、可用技能、可审计账本）。
>   **这是全馆最重要的定性判断**：它解释了为什么「不耗散就退化」——停止注入资源，记忆/上下文就退化为无信息（10 卷 §5.3 过平滑）。因此「**零成本长期运行**」在理论上**不可能维持有序**，只能维持「低质量平衡态」。这不是工程缺陷，是热力学约束。
>   **推论**：`runtimeTelemetry` 若记录「每单位产出的耗散量」，那就是**热力学效率**；这是比「tokens/task」更本质的效率指标。

## 3. Landauer 原理：能耗下界是**多远**、真正的墙在哪

```
Landauer: 擦除一个比特至少耗散  E_min = k_B T ln2
           室温 (T=300K):  ≈ 2.9 × 10⁻²¹ J ≈ 3 zJ
```

**前沿测算（源，可核实）**：对一个参考规模模型的单 token 前向：

- 不可逆位操作量级约 $10^{12}$ ⇒ **Landauer 下界 ≈ 3 nJ/token**；
- **实测单流 token ≈ 1 J**；
- 逻辑门切换能量下界 ≈ 数十 mJ/token；
- **真正的物理瓶颈是数据搬运**（decode 阶段把权重从 HBM 流出来）：$2.6\times10^{10}$ 字节 × ~2×10⁻¹¹ J/字节 ≈ **0.52 J/token**（batch=1）。

**三条结论（推论）**：

> ① **当前推理比 Landauer 极限高 8–9 个数量级**——「逼近热力学极限」不是近期工程议题。任何引用 Landauer 来做「我们很省电」的论证都是滥用。
> ② **真正的墙是 memory wall（数据搬运）**：降本路径是**降精度**（搬运更少字节）与**提批复用**（每个搬运的字节服务更多 token）。
> ③ 对本仓库最相关的一条：**「算力换质量」的边际收益遵循同一逻辑**——当任务简单时，额外算力买到的是「搬运了更多字节却没增加判别信息」，**收益趋零**（与 10 卷 §2.2 的 EFE 结论一致，两条独立路径得到同一结论，可信度提高）。
>
> **对 `genesis/ledger.ts` 的诚实要求**：该账本的 `joules` 是**每 token 经验系数的估算代理值**（文档已坦白）。本馆确认这一坦白**必须保留**——它是「会计不变量」而非物理量，引用 Landauer 会立刻使它失效（见 §9）。

**另一条前沿（值得记账）**：有工作形式化「**热力学解耦**」——LLM 的输出熵与因果准确率统计独立（对同一模型跨任务，输出熵几乎不变而准确率 0%→100%）。即：**物理代价与认知错误无关**（$\partial E_{cost}/\partial \varepsilon = 0$）。

> **推论（对本仓库有直接价值）**：这意味着**「输出熵」不能作为正确性的代理**——不能因为模型「显得不确定」就认为它更可能错，也不能因为「显得确定」就信它。**因此校准必须靠外部 verifiable verdict（RLVR），而不能靠模型自身的熵。** 这条为 02 卷的 RLVR 主线提供了独立的理论理由。

## 4. 相变与临界：结晶、对称破缺的真实机制

```
序参量 m:       无序相 m = 0；有序相 m ≠ 0
临界温度 T_c:   m ~ (T_c − T)^β  （临界指数 β）
自发对称破缺:   哈密顿量对称，但基态（或平衡态）不再对称
成核与亚稳态:   亚稳态寿命 ~ exp(ΔG*/k_BT)，ΔG* 为成核势垒
                新相需越过势垒（或依赖异质成核点）才能生长
```

> **本仓库（`adapters/skill/capabilityCrystallizer.ts` / `monitoring/symmetryBreakingEngine.ts`）**：
>
> - 「结晶」在物理上是**一级相变 + 成核**。当前实现若只是「阈值固化」（置信度 > θ 则固化为技能），那是 **L0**。
> - **升到 L1/L2 的最小改动**：引入**序参量**（如「技能被复用的次数占比」）与**成核势垒**（技能从「候选」到「固化」需要跨越的最小证据量，而非一个阈值）。这样会有**亚稳态**行为——反复出现但未达势垒的技能保持「液态」可修改，达势垒才「结晶」。**这在工程上直接解决「过早固化技能」的问题**（对应 02 卷技能粒度约束）。
> - 「对称破缺」要成立必须**先定义对称群与序参量**。当前未定义 ⇒ 维持 L0，应**诚实标注**或补定义。

## 5. 输运与扩散：真 PDE，不是比喻

```
Fick 第一定律:  J = −D ∇u
   第二定律:    ∂u/∂t = D ∇²u                （热方程 / 扩散方程）
反应-扩散:      ∂u/∂t = D_u ∇²u + f(u,v)
                ∂v/∂t = D_v ∇²v + g(u,v)
Turing 不稳定性（图灵斑图）条件：
   活化剂扩散慢、抑制剂扩散快（D_inhibitor ≫ D_activator）
   且反应项具有适当的自催化结构
```

> **本仓库（`adapters/memory/heatEquationAnnealer.ts`）**：
> 这是本仓库**罕见的 L2（动力学同构）** 实现——它真做扩散步，而不是「名字里有热」。
> **升到 L3 需要**：① 离散格式的**稳定性条件**（显式欧拉需 $D\Delta t/\Delta x^2 \le 1/2$，否则发散）必须有测试或守卫；② 冷却调度的收敛性声明要与 10 卷 §4.2 对齐（几何冷却只能称近似）。
> **新方向（原创）**：形如 `heatEquationAnnealer` 的扩散算子若配上 Turing 条件，可以**产生空间斑图**——这意味着**记忆/上下文的「区域化」可以自发涌现**（而不是手工划分模块）。这是一个**未开发的零依赖方向**，成本是把 $f,g$ 设计成自催化-抑制对。

## 6. 场与耦合振子：Kuramoto 同步 = 「共振」的严格版本

```
Kuramoto:  dθ_i/dt = ω_i + (K/N) Σ_j sin(θ_j − θ_i)
序参量:     r e^{iψ} = (1/N) Σ_j e^{iθ_j}     r ∈ [0,1] 为同步度
临界耦合:   K_c = 2 / (π g(0))   （g 为自然频率分布）
```

**性质**：$K < K_c$ 时 $r \approx 0$（异步）；$K > K_c$ 时 $r$ 随 $K$ **连续**上升（二级相变）；还有**爆炸同步**（explosive synchronization，一级相变）等变体。

> **本仓库（`resonantFieldEngine`，U1 统一基板）**：
> 「共振」当前是**相似度/邻接连通**（静态图上的分数），**没有相位、没有动力学、没有序参量** ⇒ **L0→L1**。
> **升到 L2 的最小改动（原创、零依赖、可测）**：
> ① 给每个记忆条目一个**相位** $\theta_i$（可从写入时间或哈希导出）；
> ② 定义耦合 $K$ 为「共享标签/符号重叠度」；
> ③ 迭代 Kuramoto 步，得到**同步度 $r$**；
> ④ **用 $r$ 作检索的聚类信号**：高 $r$ 的簇即「共振簇」。
> **这可证伪**：若 $r$ 的簇与 BM25 的簇高度重合，说明 $r$ 无新信息（**应放弃**）；若不重合且召回升，则「共振」第一次有了严格依据。
> **这是本馆推荐的最有辨识度的理论升级点**：它把「共振」从命名变成动力学，且给出**失败判据**。

## 7. 拓扑与孤子：涡环的「拓扑荷守恒」

```
拓扑荷（守恒量）:  Q = (1/2π) ∮ ∇φ · dl ∈ ℤ     缠绕数
孤子:              非线性波包，形状稳定，因拓扑/守恒律不能连续消失
涡环:              环形涡量管，环量 Γ = ∮ v·dl 守恒（Kelvin 定理）
```

**性质**：拓扑荷是**整数**，只能通过「湮灭」或「隧穿」改变，不能连续衰减 ⇒ **拓扑保护**。

> **本仓库（`adapters/spill/vortexRingPacket.ts`）**：
> 「涡环包」当前是**打包/外溢语义** ⇒ **L0**。
> **若要让名字成立**（原创建议）：给包定义一个**整数不变量**（如「片段总数」或「片段 ID 集合的基数」），并保证**任何拆分/合并操作保持该不变量**（拆分后子包不变量之和 = 父包不变量）。这样一个包的信息**不可能因传递而静默丢失**——这正是「拓扑保护」在软件里的确切含义：**信息守恒由不变量守卫，而不是靠约定**。
> **代价**：几乎为零（一个计数 + 断言）。**收益**：把「外溢会导致信息丢失」这类风险变成**编译/运行时不可能**。这条是**本馆认为最划算的 L0→L2 升级**之一。

## 8. 纠错码：把 QEC 从「量子神秘」还原为「编码理论」

**诚实还原（本馆立场）**：

> 本仓库的 `qecEncoder` 名字指向量子纠错，但**实现不涉及量子态**。真正可用的、有理论支撑的类比是**经典纠错/检错编码**：

```
经典（线性）码:  C ⊆ F_2^n 为线性子空间；码距 d = 最小非零码字重量
奇偶校验:        H c = 0；syndrome s = H r（r 为接收字）
检错/纠错能力:   可检 ≤ d−1 个错，可纠 ≤ ⌊(d−1)/2⌋ 个错
稳定子码（量子）: 用 Clifford 群元素定义；表面码 = 拓扑码（局域校验 + 高阈值）
```

**性质**：**syndrome 只依赖错误模式**（不依赖被编码的原始信息）——这是纠错的核心洞见。

> **对本仓库的落地建议（原创）**：
> ① **改名或显式声明**：把「QEC」在文档中定义清楚为「**轨迹级 syndrome 检测**」，即：用一组**校验关系**（不变量）去检验轨迹，偏离即 syndrome。这在 UCE 里正是「守恒校验」。
> ② **具体可实现的校验关系**（零依赖）：
>
> - 账本闭合（`ledger` 已有）；
> - 每个 tool_call 必有对应 tool_result（本仓库记忆里已有该教训：拒绝工具须补记 toolCall 防悬空 ID）；
> - token 计数与消息长度的一致性；
> - 每个文件编辑必须绑定一次读取（防止盲改）。
>   ③ **为什么叫「纠错」**：单靠检测只能失败退出；**纠错的本质是冗余**——保留足够冗余（如轨迹的双写/校验和）才能**定位并修复**。因此若要「自愈」，必须先决定**在何处引入冗余**（这是设计决策，不是算法）。
>   **这条把玄学还原成工程决策**：`qec` 的成熟度取决于「有没有定义校验关系与冗余」，而不是有没有量子。

## 9. 守恒律与 Noether —— **必须画清的边界**

```
Noether 定理:  每一个连续对称性 ⇔ 一个守恒量
               （时间平移 → 能量；空间平移 → 动量；旋转 → 角动量）
物理守恒:      由对称性保证，是被证伪测试过的自然规律。
```

> **本馆最重要的一条诚实声明**：
> 本仓库的「守恒」（`genesis/ledger.ts` 的 record/commit 闭合、UCE 的「认知能量 C」）是**记账不变量（accounting invariant）**，**不是物理守恒量**。
> 区别是本质的：
>
> - 物理守恒有**对称性来源**（Noether）且**不可违反**；
> - 记账不变量**可以被违反**（就是 bug），它的价值恰恰在于**违反时能被检出**——它是一个**断言（assertion）**，不是定律。
>   **因此**：写文档时可以说「这是一个不变量 / 一个守恒式」，**不能说「符合能量守恒定律」**。后者会让评审者立刻失去信任，且把**可被违反的断言**伪装成**不可违反的定律**，掩盖了它的真实作用（错误检测）。
>   **建议措辞**：「账本闭合不变量（可检测遗漏）」，而不是「认知能量守恒律」。

## 10. 前沿：热力学计算（远期观察）

- **平衡态可微计算蓝图**（arXiv 2607.16183）：欠阻尼 Langevin 动力学的稳态是 Gibbs 分布 $\pi_\theta(x) \propto e^{-\beta U_\theta(x)}$，因此**任何可物理构造的势 $U_\theta$ 都是可编程热采样器**；可构造势使 sigmoid / softmax / 矩阵-向量积 = 热期望；梯度律 $\partial E[y]/\partial\theta = -\mathrm{Cov}(y, \partial E_\theta/\partial\theta)$ 把反向传播变成**协方差测量**。已做出超导双势阱「热力学神经元」原型。
  **诚实标注**：作者自认 transformer 的 layer-norm 块不是平衡态实现；芯片能耗估算**不含低温/控制/校准开销**。
  **对本仓库**：**不适用**（需要专用硬件）。但它的**思想**可用：**「把优化变成采样」**——本仓库的 `particleFilterBelief` 已在做 Monte Carlo 采样，方向一致。
- **Cognitive Kardashev 量表**（arXiv 2605.22840）：把算力效率按量级列表（人脑皮层 20W 约 $5\times10^{13}$–$5\times10^{15}$ ops/J；Landauer 极限 $3.5\times10^{20}$ 位操作/J）。用于建立**跨系统可比性**，但作者明确警告**单位不可严格通约**（FLOP/J ≠ 位操作/J）。
  **对本仓库**：可用于「效率指标的横向可比性」讨论时的**校准参照**，不可直接引用为性能声明。
