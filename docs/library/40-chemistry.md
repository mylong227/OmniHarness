# 40 · 化学：反应动力学、自催化、耗散结构与化学计算

> 归档 2026-09-12 | 本卷给本仓库提供**最被低估的一根支柱**：化学计算的核心命题是「**介质 + 外部调制 = 计算**」——这与 harness 的本质定义**结构同构**。

---

## 1. 反应动力学：Arrhenius 与 Metropolis 是同一个指数

```
质量作用定律:  速率 v = k Π_i [C_i]^{n_i}
Arrhenius:     k = A exp(−Ea / (R T))
               ⇒ 反应速率随温度按指数上升，瓶颈是活化能 Ea
```

**关键同构（本馆强调）**：
```
Arrhenius 因子    exp(−Ea/(R T))     —— 「越难越过势垒的事，概率越低」
Metropolis 接受   exp(−ΔE / T)        —— 「越费劲的移动，被接受的概率越低」
Boltzmann 因子    exp(−ΔE /(k_B T))   —— 「高能态出现概率越低」
softmax(z/τ)      exp(z/τ)/Σ          —— 同上，z = −E
```
**这四者是同一个数学对象**（指数族 + 温度）。

> **对本仓库的推论（可直接落地）**：
> 因为 softmax（采样温度）、Metropolis（接受劣解）、Arrhenius（活化能）、Boltzmann（模态占据）是**同一函数**，所以本仓库里**所有带「温度」的地方应当共享一条调度曲线**，而不是各自硬编码：
> - LLM 采样温度 τ（模型侧）；
> - `regime`/`prune` 的接受概率（若按 20 卷 §1 改为 Metropolis）；
> - `heatEquationAnnealer` 的冷却调度。
> **可操作**：抽出一个**温度调度器**（零依赖，一个函数），三处共用。收益：行为一致、可统一调优、可统一解释。
> **注意**：这**不是**「统一抽象」的堆砌——它成立的**唯一理由**是四者数学同源（有方程支撑），符合「一功能一类」的军规且不制造耦合。

## 2. 自催化与振荡：Hopf 分岔的化学版本

```
Lotka–Volterra（捕食-猎物）:
    dx/dt = αx − βxy
    dy/dt = δxy − γy            ⇒ 中心型（保守）振荡

Brusselator（Prigogine 学派三元自催化模型）:
    dx/dt = A − (B+1)x + x²y
    dy/dt = Bx − x²y             ⇒ B > 1 + A² 时经 Hopf 分岔产生极限环

Oregonator（BZ 反应简化模型，振荡化学的实测范式）:
    以 HBrO2、Ce⁴⁺ 等为变量的多步自催化 ⇒ 周期振荡、行波、斑图

Selkov–Gray–Scott（立方自催化）:
    du/dt = −u v² + a(1−u)
    dv/dt =  u v² − (a+b) v     ⇒ 双稳态 / 振荡，常用作化学计算介质
```

**性质**：
- **Hopf 分岔**：参数越过临界值 ⇒ 平衡点失稳 ⇒ 出现**极限环**（自激振荡，不衰减）。
- **双稳态**：存在两个稳定吸引子 ⇒ 可作**记忆/开关**（这是化学计算的基础）。

> **对本仓库（`evolution`/`spark` 的周期性行为 + `regime`）**：
> ① **振荡未必是 bug**：自催化结构下振荡是动力学必然。判据是「是否有一对特征值穿越虚轴」（10 卷 §6）。若本仓库的周期发射是设计意图，应显式记录其**参数区间**（对应当前处在 Hopf 分岔哪一侧）。
> ② **双稳态 = 记忆的化学原型**：这与 20 卷 §4 的「亚稳态/成核势垒」配套——**记忆的写入本质是「把一个系统推过势垒进入另一个吸引域」**。这给「记忆巩固」一个严格的物理图像：**巩固 = 加大势垒深度（更难忘记），而不仅是提高权重**。

## 3. 耗散结构与耗散自组装：秩序靠「持续供给」维持

```
Prigogine 耗散结构:
   远离平衡的开放系统，靠持续的物质/能量通量
   自发形成并维持时空有序结构（"order through fluctuations"）

耗散自组装（fuel-driven DSA）:
   单体被化学燃料短暂激活 → 组装 → 被去激活 → 解离
   结构只在燃料持续供给时存在；停止供燃料 ⇒ 结构消失
```

**前沿实证（源）**：2026 年有工作给出**燃料驱动超分子聚合的最小反应-输运框架**（arXiv 2601.15662）：把「激活-去激活化学」与「协同组装、断裂、长度依赖扩散」耦合，通过 **Hopf 分岔**产生**自发振荡**；引入输运后，时间不稳定演化为**空间自组织**——出现**行波聚合前沿**、振荡波与复杂时空斑图，前沿呈**近弹道动力学**（源于反应反馈与动态扩散率）。

**关键论断**：**这类结构的「存在」完全依赖持续能量耗散**——这就是「耗散」二字的含义。

> **对本仓库（**这是本卷最重要的一条映射**）**：
> 02 卷已指出「技能/记忆会退化」；20 卷 §2 判定本仓库是**开放耗散系统**。化学在这里给出**可操作的图像**：
> **「激活 / 组装 / 去激活 / 解离」四步循环 = 记忆与技能的生命周期。**
> 本仓库当前缺的正是**去激活与解离**（只有写入与检索，没有主动遗忘）。
> **可操作（原创，零依赖）**：把记忆条目建成「激活态 vs 基态」：
> - 被检索/复用 ⇒ 充能（激活）；
> - 长时间未被复用 ⇒ 自动去激活（衰减）；
> - 去激活到阈下 ⇒ 解离（归档/删除）。
> 这**就是** `memoryAnnealing` 应当实现的东西（当前 L0）。**化学给出的是一条经过验证的动力学骨架**，不是新隐喻。
> **并且它直接解掉 02 卷 §2.1 的 Ghost Memory 问题**：解离机制天然清除过期事实。

## 4. 超循环与催化闭合：技能/工具互相催化的原型

```
Eigen–Schuster 超循环:
   一组自复制单元互相催化（A 助 B、B 助 C、C 助 A…）
   形成闭合的催化网络 ⇒ 整体自维持、可共同进化
   超循环是「分子到生命」过渡的关键机制候选

RAF（reflexively autocatalytic and food-generated）集合:
   每个反应都被集合内某催化剂催化，且所有反应物可从「食物集」生成
```

**性质**：**闭合性**（网络内部互相催化）与**自生成性**（不需要外部提供中间物）是「自维持」的充要结构条件。

> **对本仓库（`skill/elementComposer.ts` + `capabilityCrystallizer.ts` + 工具系统）**：
> **「技能互相催化」在本仓库已具雏形**：技能可以调用工具、组合工具、复用其它技能。
> **可检验问题（原创）**：本仓库的技能/工具网络是**超循环（闭合）**还是**树（依赖外部）**？
> - 判据：是否存在一组「互相催化且不依赖外部新增」的闭合子集（**强连通分量 + 食物集可达性**）；
> - 若有，则系统具备**自维持能力**（在给定基础工具下能自造新技能）；
> - 若无，则「自我改进」其实是**人工驱动的**，不应声称「自主演化」。
> **零依赖可算**：强连通分量（Tarjan）+ 可达性判断。**这是一个能把「自主进化」从宣称变成事实的高价值检查。**
> **注意**：Eigen 超循环有一个**已知风险**——**超循环内部寄生**（不做贡献却分享收益的单元）。本仓库的「技能寄生」判据：**只被引用、从不产生增益的技能**。这是一个可扫出来的清单。

## 5. 反应-扩散与图灵斑图：区域化的自发来源

```
∂u/∂t = D_u ∇²u + f(u,v)
∂v/∂t = D_v ∇²v + g(u,v)

图灵不稳定性（自发斑图的充要直觉）:
   ① 无扩散时体系稳定（反应项是稳定的）
   ② 扩散使体系失稳（"diffusion-driven instability"）
   ③ 需要 D_inhibitor ≫ D_activator（抑制剂扩散更快）
```

**性质**：**均匀态**在扩散下失稳，自发形成**斑点/条纹/迷宫**等空间结构——这是「无预置模板的自组织区域化」。

> **对本仓库（`context/` 的模块/文件分区 + `heatEquationAnnealer`）**：
> **模块边界能不能自发生成？** 图灵机制给出一条**可实验的路径**：
> - $u$ = 「文件/符号的激活度」（被引用、被编辑的强度）；
> - $v$ = 「抑制量」（跨模块耦合度）；
> - 若 $D_v \gg D_u$（抑制扩散更快），则**会自发涌现出稳定的模块分区**——即**代码聚类/边界**可以从耦合动力学中**长出来**，而不是靠人手工划分。
> **诚实边界**：这是**研究性方向**，需要先把 $f,g,D$ 标定到「代码语义」上，且**必须与前缀稳定性（`prefixStability`）等既有守卫兼容**。**不建议**在重构期引入。**列为远期观察**，但它确实回答了一个本仓库当前的困境：**目录分区靠人工决策**（`REFACTOR_BOARD` 的 P3）。图灵机制提示：**分区可以是动力学的涌现，而不是一次性的组织行为**。

## 6. 化学计算：「介质 + 调制 = 计算」——与 harness 的本质同构

**核心事实**：
- 化学反应网络（CRN）在理论上**图灵完备**；
- **DNA 链置换**可实现任意 CRN 的近似动力学（含反应-扩散与斑图）；
- **动态调制外部条件**可把化学介质转成逻辑门：把 Selkov-Gray-Scott（立方自催化）转成 **NAND 门**（arXiv 1807.00031）；
- 更进一步：对**延展的**（非良好混合的）化学介质做**时空调制**，可造出**多个门并互联**，用**扩散**做门间信息传递，实现**全加器电路**（arXiv 1908.11510）；
- **双稳态是关键前提**：它提供「纠错/记忆」——轨迹趋近平衡点使小扰动被吸收（"categorization step 是一种纠错"）；
- **可逆（NAND/NOR）是通用计算的门槛**：只有 AND/OR 无法组合出任意布尔函数。

> **本仓库最重要的跨学科映射（本馆论断）**：
> ```
> 化学计算：  化学介质（非线性动力学）  +  外部参数调制（时空）  ⇒  计算
> Harness：   模型（非确定性推理）      +  钩子/门禁/压缩（确定性调制）⇒ 可靠执行
> ```
> **这不是比喻，是结构同构**：
> - 化学里**计算能力来自介质的非线性**，而**可靠性来自外部调制**；harness 里**智能来自模型**，**可靠性来自 harness**——01 卷的 `Agent = Model + Harness` 在化学里有完全平行的命题。
> - 化学里**调制序列决定输出**（同一介质可实时重编程为不同逻辑）；harness 里**同模型经不同 harness 得到不同分数**（LangChain 52.8→66.5，Vercel 80→100）。**两者都是「介质不变、调制改变 ⇒ 输出改变」**。
> - 化学里**双稳态提供纠错**；harness 里**门禁链提供 fail-closed**。**同一功能，不同实现。**
>
> **推论（可直接落地）**：
> ① **把「调制」当一等公民**：本仓库的 hooks/门禁是「调制器」，它们的能力边界（能拦什么、不能拦什么）应当**显式清单化**，像化学家标定「可调制的参数空间」一样。**没有清单的调制 = 不可复现的计算。**
> ② **双稳态的启示**：「唯一稳定答案」比「多候选」更适合做**门禁**——因此门禁判定应当**收敛到二元 verdict**（通过/不通过），而不要在门禁里做模糊打分。**这是为什么 fail-closed 是对的**：单稳态，无中间态。
> ③ **通用性的门槛**：化学里 NAND/NOR 才是通用门。harness 里，**「拒绝能力」是通用性的门槛**——一个只能执行的 harness（无拒绝）无法组合出任意可靠行为。本仓库已有四级审批与 fail-closed，**方向正确**。

## 7. 局限与不做清单

| 不做 | 原因 |
|---|---|
| 真实化学反应/湿实验 | 与本项目无关 |
| 用化学振荡器物理实现计算 | 无硬件，且成本远超收益 |
| 把「分子数目」类比为「token 数」做定量换算 | 单位不可通约，会产出伪精确结论（与 20 卷 §10 的同类错误） |
| 把化学反应网络的图灵完备性当「本项目也能通用计算」的论据 | 图灵完备是**介质**的性质，不是**工程系统**的性质 |

**只取**：动力学骨架（自催化/振荡/双稳态）、结构条件（闭合、超循环）、调制范式（介质+调制）。
