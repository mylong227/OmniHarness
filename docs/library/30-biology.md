# 30 · 生物：进化、免疫、预测编码、稳态与自组织

> 本卷把它们**逐个还原为可检验的算法**，并指出**哪些是天然同构、哪些是难度被低估了**。

## 1. 进化：适应度地形的形状决定了能不能爬上去

### 1.1 基本机制

```
变异—选择—遗传循环：  x_{t+1} ~ mutate( select( x_t ) )
适应度:               w(x)  （此处 = verifiable verdict：编译/测试/类型检查）
Wright–Fisher 漂移:    有限种群下，即使中性也有频率随机漂移（遗传漂变）
Red Queen:            相对适应度（对手也在变）⇒ 不进步就是退步
```

**关键概念：地形崎岖度（ruggedness）**。用 **NK 模型**刻画：

```
N 个位点，每个位点与 K 个其他位点相互作用 ⇒ 适应度地形崎岖度随 K 上升
K = 0: 单峰光滑地形（爬山法必达全局最优）
K = N−1: 完全随机地形（任何局部搜索都无用）
真实问题通常在中段：多局部最优，需要「跳出」机制
```

> **对本仓库（`evolution/evolutionControllerImpl.ts` + `twistDiscoveryEngine.ts`）**：
> ① **「进化闭环」必须显式面对地形崎岖度**。若没有跳出机制（重启、大变异、种群多样性、模拟退火接受劣解），就只能在局部最优里打转——**这正是 RAGEN「Echo Trap」在生物语言里的描述：种群失去多样性后陷入自说自话**（见 02 卷 §1）。
> ② **可操作**：把「新策略与历史策略的**多样性度量**」（而非仅适应度）作为保留判据。**多样性是抗 Echo Trap 的通用第一道防线**，且零依赖（集合距离即可）。
> ③ **诚实**：本仓库的 verifiable verdict（编译/测试绿）覆盖的任务比例**决定这套机制是否真在「进化」**。若只有 10% 的步骤有 verdict，那其余 90% 是随机游走。**这份覆盖率报告是第一优先级的诊断**（已列 02 卷 L3）。

### 1.2 退火 vs 进化策略

```
模拟退火：单点 + 温度接受劣解（见 10 卷 §4.2）
(1+1)-EA：单点 + 严格接受更优解（温度恒为 0 的退火）
```

**性质**：**退火 ≥ (1+1)-EA**（退火包含其全部行为，且多了跳出机制）。因此若本仓库的进化闭环严格只接受更优解，则它**弱于**同等的退火——**这是一个可以立刻改的免费增益**（允许小概率接受劣解）。

## 2. 免疫系统：Agent 安全最贴切的理论源

### 2.1 四套机制（可直接映射）

| 机制         | 内容                                                                                                                              | 映射到本仓库                                      |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| **阴性选择** | T 细胞在胸腺中被训练为**不攻击自身**（对 self 反应者凋亡）；由此得到「非我」识别                                                  | 定义「正常调用序列」的黑名单式排除 → 异常调用检测 |
| **克隆选择** | 亲和度高的 B 细胞被选中、大量分裂、**体细胞超变异**                                                                               | 高适应度策略的复制 + 变异（= 进化的免疫版本）     |
| **亲和成熟** | 反复选择-变异，「抗体」对「抗原」结合力递增                                                                                       | 策略对特定任务族的特化                            |
| **危险理论** | 免疫不响应「外来物」，而响应**损伤信号**；发展出**树突细胞算法（DCA）**：聚合 PAMPs / 安全信号 / 危险信号做**上下文感知异常检测** | 不按「是否陌生」告警，而按「是否造成损害」告警    |

> **对本仓库（`adapters/monitoring/immuneMonitor.ts`）**：
> 当前是监控框架（L0→L1）。**最有价值的升级路径（原创）**：
> ① **直接对标 Agent 安全前沿量化 benchmark**——`AgentDojo`、`InjecAgent`（间接提示注入）；把免疫监控接上去，做**可复现的拦截率**，而不是停留在「有监控」。
> ② **采用危险理论而非自/非自**：1 卷 §5 已指出 MCP 协议层**没有在「工具描述」与「用户内容」间做语义隔离**。这意味着**「陌生工具描述」是合法输入，告警无意义**。危险理论告诉我们该看的是**损害信号**：是否试图越权（写系统路径）、是否外发数据（SSRF 已有 `ssrfGuard`）、是否重复修改同一处（反漂移）。**这三条比「是否陌生」强得多。**
> ③ **可操作的新不变量**：危险信号 = 「一次会话中出现的越权尝试次数」。它可度量、可回归门禁。

### 2.2 冗余（redundancy）vs 退化（degeneracy）——**关键区分**

```
冗余:     同一路径的多个副本（备份）—— 单点故障的对抗
退化:     不同路径达成同一功能（结构不同、功能相同）—— 鲁棒的真正来源
```

**源（生物理论）**：**退化而非冗余**才是生物鲁棒性的主因，且被认为与**开放式学习与进化**密切相关。

> **本仓库推论（对本项目「低耦合、可移植」目标直接有用）**：
> 「低耦合」的**真正判据**不是「没有互相引用」，而是**功能退化性**：同一能力是否有多条**结构不同**的达成路径。
> **可操作测试**：构造「移除某模块后能力是否仍可达（哪怕性能下降）」的测试。能，则该能力具备退化性（真解耦）；不能，则是**伪装成解耦的单点**——无论 import 图多干净。
> 这条比「依赖方向审计」（`REFACTOR_BOARD` 的 P1）**更本质**，且两者互补：P1 保证单向，退化性保证**可替代**。

## 3. 神经与预测编码：注意力 = 精度加权

```
预测编码:     自上而下生成预测，自下而上送回「预测误差」
学习/推断:    最小化预测误差（等价于最小化变分自由能，见 10 卷 §2）
精度加权:     ε 被按「估计的可靠性」加权；高精度 ⇒ 该误差被放大
              ⇒ 这**就是注意力**的机制解释（增益调制）
层次生成模型: 高层表征「慢变量/原因」，低层表征「快变量/细节」
```

**前沿实证（源）**：2026 年 _Science Advances_ 有工作用**基于自由能原理的分层多模态递归网络**直接处理约 3 万维视觉-本体感受输入（不降维、不手工预处理），在全身人形机器人的两项护理任务上端到端学习预测；观察到三个**涌现性质**：① 自组织的分层潜动态（管理任务切换/不确定性/遮挡推断）；② 视觉退化下的鲁棒性（多模态互补）；③ 多任务学习的**不对称干扰**。

> **对本仓库（`context/contextAssembler.ts` 的注意力配额 + `modalityPort.ts`）**：
> ① **「注意力」应当是精度加权，而不是平均分配**。这给 10 卷 §1.2（最大熵配额分配）提供了**生物侧的独立佐证**：注意力 = 按可靠性加权，故「不可靠来源的误差应被压低」。**可操作**：给每个上下文来源（repo-map / 记忆 / 工具结果）一个**可靠性权重**，按任务动态调整，而不是固定预算切分。
> ② **多模态互补带来鲁棒性**——本仓库已有模态函子（L3）。**但「不对称干扰」这条必须记账**：多任务共享表征会互相干扰，**且干扰是不对称的**（某个方向受损更重）。因此「多模态融合」不是免费午餐，需要**任务分组实验**来量化干扰。这是一个**没人提但现在就能测**的风险点。

## 4. 稳态与稳态调节（Homeostasis / Allostasis）

```
稳态:      把关键变量维持在集合点（set point）附近（负反馈）
稳态调节:  预测性调节——**预先**改变集合点以应对将要发生的事，而非事后纠偏
存续约束:  系统只在「可存活区域」(viability kernel) 内才存在
```

> **对本仓库（`genesis/regime.ts` 的「模态数 ≥ 1」）**：
> 「模态数有下界 ⇒ 不会把自己剪空」在生物语言里精确对应**存续约束（viability constraint）**。这是本仓库**少见的、天然同构的设计**（L1→L3 之间：单调性 + 下界都已有测试）。
> **推论（原创、可直接落地）**：
> 把「存续约束」**推广**为一条通用护栏——**每个自适应子系统都必须声明自己的 viability 集合与不可越过的下界**：
>
> - 上下文预算：不可低于「系统提示 + 当前任务」的最低需求；
> - 技能库：不可剪到 0；
> - 记忆：不可退化为空（否则退化为无状态）。
>   **可操作**：在 `regime` 的范式上，为每个子系统加「下界不变量 + 触界即停机」的断言。**这是把 L3 的成熟度复制到其它子系统的模板。**

## 5. 群体智能与「单写者」护栏

```
蚁群优化 (ACO):     信息素 τ 正反馈 + 挥发 ⇒ 路径收敛
粒子群 (PSO):       个体最优 + 群体最优 牵引
Stigmergy:          通过**改造环境**间接通信（无需直接消息）
涌现:               简单局部规则 ⇒ 全局优化行为，无中心协调
```

**代价（源）**：生物式浪费是特征（大量个体失败换取鲁棒解），在工程上代价高；且**可解释性差**。
**关键工程护栏（源，Cognition 反模式）**：**多智能体只用于「读/分析」，写操作保持单写者线程。**

> **对本仓库（`worker/workerOrchestrator.ts`、`subagent/`、`autonomy/workflowRunner.ts`）**：
> ① 并发 fan-out 适用于**检索/分析/审查**；**写代码必须单写者**。这条应与 `worktree.ts`（隔离工作树）配合：并行只在独立工作树内安全。
> ② **Stigmergy 的直接映射**：本仓库的**文件系统 + 审计链**就是环境媒介——子体通过写文件/记录协作，而非消息传递。这与 01 卷「文件系统是天然协作面」一致。
> ③ **诚实代价**：ACO/PSO 类方法在**静态、可精确求解**的问题上不如精确算法。本仓库的任务调度若是 DAG 上的确定问题，**不应引入群智能**（会牺牲最优性换鲁棒性，得不偿失）。**只在「目标函数不可微、梯度不可得」的场景才用**。

## 6. 自创生与「组织闭合」：账本的真正生物原型

```
自创生 (Autopoiesis, Maturana & Varela):
  一个「生产网络」，其产物**递归地参与生产自身**（组织闭合）
  且在网络存在的空间里实现为一个整体（空间闭合）
超循环 (Eigen & Schuster): 催化循环互相催化，形成自维持的闭合网络
```

**源（化学/生物交界）**：自创生把 Prigogine 的耗散结构、Eigen 的超循环、以及「秩序优先」的观点统一起来；关键论断是「**同一组织可由不同组分实现**」（多重可实现性）。

> **对本仓库（`genesis/ledger.ts` 的 record↔commit 闭合）**：
> 这是**「组织闭合」在会计上的对应物**：每一笔能量/资源流动都参与并维持这个账本自身的完整性（记录→结算→可审计）。**这个映射比「能量守恒」准确得多**（见 20 卷 §9）。
> **多重可实现性**是本仓库「可移植」目标的**理论依据**：**架构（组织）不变，实现（组分）可换**。这与 11 卷 §2 的函子定律是同一件事的两种语言——**函子定律 = 多重可实现性的可计算判据**。
> **推论**：一个模块是否「可移植」，判据是「把它换成一个满足同一函子定律的不同实现，系统是否仍正确」。**这是可测试的定义。**

## 7. 脑的能量效率（作为「稀疏」的动机，但要诚实）

```
人脑:      ~20 W，~10^14 突触，稀疏（任一时刻仅 1–5% 神经元活跃）
单 GPU:    300–700 W（峰值），默认稠密激活
```

**性质**：脑的高效主要来自**稀疏 + 事件驱动 + 存算一体（模拟）**，不是算法上的某个技巧。

> **对本仓库的边界声明**：
> 本仓库是**软件 harness**，不控制硬件。因此**不能引用脑效率为自己的性能背书**。真正可用的启发只有一条：**条件计算（只激活需要的部分）**——本仓库的 `tool_search`、技能按需加载、子体隔离都是这个方向的软件版。
> **诚实结论**：脑效率作为**动机**是合理的（说明稀疏有巨大上限），作为**成果**是虚假的。本卷明确记下这条，防止日后被误引。

## 8. 本卷映射小结与升格路径

| 隐喻               | 现状                | 升格路径                                                                      | 关键检验                                   |
| ------------------ | ------------------- | ----------------------------------------------------------------------------- | ------------------------------------------ |
| 进化闭环           | L1                  | 加**多样性保留** + 允许接受劣解（退火化）                                     | 同 corpus 开关隔离，适应度曲线是否单调改善 |
| 免疫监控           | L0→L1               | 接 `AgentDojo`/`InjecAgent`；改用**危险信号**（越权/外发/反漂移）而非「陌生」 | 拦截率提升且误报不增                       |
| 共振记忆           | L0→L1               | 见 20 卷 §6（Kuramoto + 序参量）                                              | 簇是否与 BM25 重合（重合即无新信息）       |
| 元认知 / 信念      | L2                  | 见 10 卷 §3（ESS 监控、收敛测试）                                             | 合成观测下后验收敛到真值                   |
| 账本（自创生闭合） | **L3**              | 保留；修正措辞                                                                | 已可机械检出遗漏                           |
| 存续约束（下界）   | **L3**（仅 regime） | **复制到其它子系统**                                                          | 各有下界断言 + 触界停机测试                |
