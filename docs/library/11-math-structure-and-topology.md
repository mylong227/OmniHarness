## 1. 代数结构：组合律是「可推演」的门票

```
半群 S:      (a·b)·c = a·(b·c)                      仅结合律
幺半群 M:    半群 + 单位元 e,  e·a = a·e = a        结合 + 单位
交换幺半群:  再满足 a·b = b·a
群 G:        每个元素有逆元 a·a⁻¹ = e
自由幺半群:  由生成元构成、无多余约束的幺半群（∗ 串接）
```

**为什么这重要（本馆立场）**：**有结合律才敢并行、才敢重排、才敢缓存**。
- 结合律 ⇒ 可分块计算（并行/流式）；
- 交换律 ⇒ 结果与顺序无关（可乱序收集）；
- 单位元 ⇒ 存在「空操作」，可增量组装。

> **本仓库（`genesis/algebra.ts`，L3）**：
> - `Cost`（tokens × joules）被构造为**交换幺半群** ⇒ 资源计量可任意顺序累加，这与「token-meter 逐次累加」的正确性直接挂钩。
> - `vectorConcat` 是**自由交换幺半群** ⇒ 多维资源无耦合地组装。
> - **可证**：结合律（浮点容差）、单位元、交换律三点都有单测。
> **这是全库最扎实的理论兑现之一。推论**：任何新的资源维度（如「显存」「网络字节」）都应**先证明它是交换幺半群的元素**再接入——这就是「可推演」的门槛，而不是新增一个 if。

## 2. 函子、自然变换、幺半群化：把「层层包装」变成定律

```
函子 F: C → D 需满足两条定律
  ① 保持恒等：F(id_A) = id_{F(A)}
  ② 保持组合：F(g ∘ f) = F(g) ∘ F(f)
```

**函子定律是「可放心组合」的许可证**：满足它，就能把 $F$ 当积木；不满足，组合就会悄悄错。

> **本仓库（`genesis/modalityPort.ts`，L3）**：`Modality.map` 满足恒等律与组合律（有单测）⇒ 多模态编码器可以**被替换**（换成 CLIP 类编码器）而代数不变。这是「**可移植**」这一优点在数学上的确切含义：**函数互换，定律不变**。
> **推论（重要）**：这条给出了判断「某个抽象是否真的可移植」的**唯一硬标准**——它是否满足函子定律并有测试。仅仅「接口长得像」不算可移植。

### 2.1 指称语义与算子幺半群

```
Operator<S> = (state: S) => { next: S; cost: Cost; events: Event[] }
composeOperator(f, g) 满足结合律；identityOperator 为单位元  ⇒  幺半群
```

> **本仓库（`genesis/operator.ts`，L3）**：因为算子是**纯函数**（无隐藏副作用），所以可**等式推理**；`composeOperator` 构成幺半群 ⇒ 算子列表可任意分组、可并行、可重排，成本经 `Cost` 幺半群累加与顺序无关。
> **这是 UCE「演变」的工程骨架**：把演进策略写成算子的组合，就自动获得了「可推演」的性质。

## 3. 范畴论：迁移、兼容与「真发现」

### 3.1 基本词汇

```
范畴 C: 对象 + 态射（可组合、有恒等）
函子:   范畴间保结构的映射（见 §2）
自然变换 η: F ⇒ G，为每个对象给一个「一致」的态射 η_A: F(A) → G(A)
Kan 扩张: 把一个函子沿另一个函子「最优地」迁移到新基底
```

### 3.2 左 Kan 扩张 = 「升级不丢历史」的形式化（**本馆重点**）

前沿工作（MIT 自修正 AI 框架，arXiv 2606.01444，**本文解读**）把「科学范式迁移」形式化如下：

```
Schema（可行操作集，一个范畴） S_old --u--> S_new     翻译函子
数据（copresheaf，即函子 I: S → Set）  I_t : S_old → Set
迁移：  左 Kan 扩张  Lan_u I_t : S_new → Set
        —— 计算「在新词汇下最一致地重新归档旧数据」，保证向后兼容

真发现 := 残差内容 (residual) = 新状态 − 迁移后的旧状态
        —— 「迁移解释不了的差额」才是真创新，而非「新增复杂度」
```

**为什么这是本图书馆最重要的外部思想之一（推论）**：
> 本项目正在做**大规模重构**（文件移动、改名、目录重组、边界收口）。按范畴论的说法，这是一次 $u: S_{old} \to S_{new}$。**风险不是「改错」，而是「迁移后无法解释的历史丢失」**。
> **可操作落地（零依赖）**：
> ① **保留迁移映射**（旧路径/旧类名 → 新路径/新类名），作为显式的 `u`——这就把「方案变更」变成可审计的对象，而不是散落在 PR 描述里；
> ② **把「残差」当 KPI**：迁移后**无法被映射解释的差异**（行为变化、测试语义变化）逐条登记——**这些才是真正的风险点**；
> ③ 反向引用（`import type` 被擦除）在范畴语言里就是「态射被遗忘」，需显式记录，否则会形成**沉默的兼容性断裂**（本仓库重构范式中已注意此点）。
> **这条把「重构安全」从工程直觉升级为可审计流程**，是本馆对现有 `REFACTOR_BOARD` 的直接补充。

### 3.3 `liftOperator` 就是函子

`genesis/operators.ts` 把 14 个既有引擎**提升**为 `HarnessOperator`（lawful morphism）。用范畴语言：
> **`lift` 是一个函子，把「引擎范畴」映射到「算子范畴」，并保持组合律。**
> 因此前提是：**原引擎必须被当作合法对象（lawful morphism）**——即它的行为必须能用纯函数语义描述。**若某引擎内部有隐藏可变状态，则 `lift` 不是函子**（破坏组合律），代数性质会静默失效。
> **这是本馆给出的一条硬检验**：为每个被 lift 的引擎写一个「组合律测试」（`lift(f ∘ g) ≡ lift(f) ∘ lift(g)`）。有则 L3，无则 L1。**这是一个可批量补齐的高价值测试套件。**

## 4. 层论：把「无后遗症」变成**公理**

这是本卷最重要的技术内容。**UCE 声称「单场 + 单账 + 单演变 ⇒ 无边界可漏」，层论正是这句话的数学形式。**

### 4.1 细胞层（cellular sheaf）

```
细胞层 F 给图上的每个节点 i 与每条边 e 各一个向量空间（stalk）：
   F(i)（节点数据空间）、F(e)（边数据空间）
以及限制映射 ρ_{i→e}: F(i) → F(e)   —— 把节点数据「翻译」到边的坐标系

一致性（共识）：邻居 i, j 在边 e 上「一致」⇔ ρ_{i→e}(x_i) = ρ_{j→e}(x_j)
层 Laplacian 恰好聚合所有「不一致」：L_F x = Σ_{i~e} ρᵀ(ρ(x_i) − ρ(x_j))
```

### 4.2 层的两条公理 = 「无后遗症」的形式

```
局部性 (locality):  两个整体截面若在每个局部一致，则它们相等
粘合  (gluing):     局部一致的截面必能粘成唯一整体截面
```

> **本馆推论（核心）**：
> UCE 说的「焊接式 N 模块 = N 套状态 + N−1 个同步边界 ⇒ 边界必漏」，在层论语言里就是：**该系统的表示不构成一个层（缺粘合公理）**——局部一致不保证全局一致，于是必须靠人工同步（= 边界）。
> 「归一」= **把表示构造成一个层（copresheaf/sheaf）**，于是**局部一致自动蕴含全局一致**，同步边界消失。
> **这给「无后遗症」一个可检验的定义**：对任意局部一致的配置，系统是否存在唯一全局态？能，则是层（L3）；不能，就是焊接（L0）。
> **可操作测试（原创）**：构造「两个局部一致但全局不同」的配置，看系统是否拒绝或消解——**能通过，就证明归一是真的**。

### 4.3 层优于普通图消息传递（有实证）

前沿结果：**层神经网络（SNN）在「异配图」（相连节点类别不同）与「过平滑」两个经典病理上优于普通 GNN**（源见参考）。原因正是**限制映射**允许「邻居在各自坐标系里比较」，而非强行用同一度量。

> **对本仓库的意义（`context/codeGraph.ts` + `context/hybridRanker.ts`）**：
> 代码图天然是**异配**的：`import` 两侧的符号**语义类型不同**（调用方是「消费者」，被调方是「提供者」），用同一内积比较是**度量错配**——这解释了两个实测负结果：
> - LSA（同一向量空间降维）抹掉判别方向（10 卷 §5.1）；
> - PageRank（同一标量分数）在稠密图上均匀化（10 卷 §5.2）。
> **建议（原创方向）**：把「节点→边」的翻译显式化（例如：函数节点在「调用边」上的坐标 = （调用深度、参数数、是否跨模块）；被调节点在同一坐标系的坐标 =（被调用频次、导出性、是否有测试）），再做一致性聚合。**这是把 repo-map 从「图上排序」升级为「层上一致性」的路线**，且**零依赖可实现**（限制映射就是一个小的、可手写的线性映射）。

## 5. 拓扑：给「结构」以不变量

```
单纯复形:   由顶点、边、三角形…组成
同调群 H_k: 第 k 维「洞」的计数（H_0 连通块数、H_1 环数、H_2 腔数）
欧拉示性数: χ = V − E + F − …  = Σ_k (−1)^k dim H_k
持久同调:   随尺度 ε 变化得到「条码」(barcode)，衡量拓扑特征的鲁棒性
```

**用途（推论）**：这些是**离散结构的不变量**——对依赖图/轨迹图，它们能回答「重构前后结构是否同型」这类问题。
> **可操作**：把 `codeReferenceGraph` 的**连通块数 $H_0$** 与**环数（独立循环依赖数 $\dim H_1 = E - V + C$）** 作为**重构的守门指标**：环数上升 = 解耦恶化。这比「看 import 数量」严格得多，且**零依赖可算**（并查集 + 计数即可，$O(E)$）。
> **这是本馆最推荐的低成本新指标**：`H_1 = E − V + C`。

## 6. 最优传输：比余弦更结构性的「共振」

```
Wasserstein 距离:  W_p(μ,ν) = ( inf_{γ ∈ Π(μ,ν)} ∫ d(x,y)^p dγ )^{1/p}
Kantorovich 对偶:  W_1(μ,ν) = sup_{‖f‖_Lip ≤ 1} | E_μ[f] − E_ν[f] |
熵正则 + Sinkhorn:  min_γ ⟨C, γ⟩ − ε H(γ)  ⇒ 迭代缩放求解，O(n² log n) 量级
```

**原理**：Wasserstein 比较的是**质量如何搬运**（含几何），余弦/内积只比较**方向**。当两个分布「支撑集不同」时，内积/JS 散度会失效，而 $W$ 仍然有意义。

> **对本仓库的意义（`resonantFieldEngine` / `resonantMemoryEngine`）**：
> 「共振匹配」目前是相似度（内积/邻接）。**真正的「共振」在数学上更接近传输/对齐**：把查询的「概率质量」搬运到记忆条目的支撑集上做的代价。
> **诚实边界（本馆判断）**：Sinkhorn 的 $O(n^2)$ 成本在长上下文场景**不可接受**；因此**不建议**把检索主路径改成 OT。
> **但有两个廉价替代**：
> ① 用 $W_1$ 的**线性时间下界近似**（沿一维投影的排序匹配，即「切片 Wasserstein」），成本 $O(n\log n)$；
> ② 只在**候选重排（rerank）**的窄集合上做 OT（Top-50 → Top-10），成本可控。
> **结论**：OT 不是替代 BM25，而是**给「共振」这个隐喻一个可证伪的正确度量**。若真要主张「共振」，就应当用传输而不只是余弦。

## 7. 信息几何：优化的正确「地形」

```
统计流形: 参数 θ 张成的空间，每点 p(x|θ)
Fisher 度量: g_ij(θ) = E[ ∂_i ln p ∂_j ln p ]
自然梯度:   θ ← θ − η g^{-1} ∇L
测地线:     该度量下的「最直路径」；距离 = 测地距离
```

**性质**：参数化无关（坐标变换下不变）；这意味着**自然梯度不受「你怎么写参数」影响**。

> **对本仓库的意义**：这是 10 卷 §3.2 的几何面。**更强的推论**：
> 「检索」在一个统计流形上，本质是**沿测地距离的近邻**问题。若把「查询」与「记忆」都看成分布（而非向量），那么：
> - 余弦 = 欧氏假设下的近邻（**只在流形近似平坦时成立**）；
> - 自然梯度/Fisher = **流形内禀度量**（一般正确）。
> 因此**「共振」若要成立，其度量应当是 Fisher/测地意义上的，而不是余弦**。这给「共振记忆」指了一条**可证伪**的路：换成 Fisher-Rao 距离，若召回无改善，则「共振」在度量层面不成立。

## 8. 类型论与效应：把「资源消耗」写进类型

```
线性类型:   A ⊸ B  ⇒ A 恰好被用一次（不可复制、不可丢弃）
仿射类型:   A → B  ⇒ A 至多用一次
效应系统:   在类型上标注副作用（IO、异常、状态），编译期检查
```

> **对本仓库的意义（推论）**：本仓库的资源铁律是「token/joules 必须入账」。在类型论语言里，这正是**线性/仿射类型**要解决的问题：**资源不可复制、不可静默丢弃**。
> TypeScript 没有线性类型，但可以**近似**：
> - 用**品牌类型**（branded type，如 `type MustCommit<T> = T & {__sealed: never}`）阻止「未结算即离开作用域」；
> - 现有 `genesis/ledger.ts` 的「record 必须 commit」其实就是**运行时的仿射类型检查**——把它形式化即可获得 `CODE_STANDARD` 里「显式胜于隐式」的更强版本。
> **这条给出一个可落地的类型级增强**，且零运行时成本（类型层擦除）。

## 9. 本卷收束：把 UCE 四公理形式化（**本馆原创**）

| 公理 | UCE 的表述 | 本卷给出的形式 | 可检验性 |
|---|---|---|---|
| **归一** | 一切皆是场中节点，无平行表示 | 表示构成 **copresheaf**；「无后遗症」⇔ 满足**局部性 + 粘合** | 构造局部一致而全局不同的配置，看是否被消解 |
| **守恒** | 认知能量在场内流转不增不减 | **记账不变量**（非物理守恒！）：record/commit 闭合 | 已 L3（`ledger` 有单测） |
| **演变** | 势函数下自发形变 | 保序映射下的**适应度爬山 + 退火**；收敛性用 **Lyapunov 单调量** 证明 | `regime.ts` 已 L3（单调 + 下界 + 不动点） |
| **度量**（新增） | ——（原框架缺） | 优化/检索/匹配都在**正确的几何**上做：Fisher-Rao / 层 Laplacian /（窄域）最优传输 | 换度量后召回是否提升（同 corpus 开关隔离） |

**为什么需要第四公理（本馆论断）**：
> UCE 的三公理解决了「表示统一 / 账目清楚 / 机制自适应」，但**没有说「在哪个空间里比较相似」**。而本仓库所有实测负结果**全部是度量错配**：
> LSA（欧氏重构 ≠ 排序保序）、PageRank（标量分数在稠密图上均匀化）、频域共振（与词袋冗余）、余弦（假设流形平坦）。
> **因此「度量」不是修饰，是缺失的一根柱子**。补上它，前面的负结果从「玄学失效」变成「可解释、可修正的度量错误」——这是本图书馆对项目最大的**认知增量**。
