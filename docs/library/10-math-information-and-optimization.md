## 1. 信息论：上下文预算的**下界**从哪来

### 1.1 基础量

```
香农熵        H(X) = − Σ_x p(x) ln p(x)
联合/条件熵    H(X,Y) = H(X) + H(Y|X)
互信息        I(X;Y) = H(X) − H(X|Y) = KL( p(x,y) ‖ p(x)p(y) )
KL 散度       KL(q‖p) = Σ q ln(q/p) ≥ 0,  等号当且仅当 q = p
交叉熵        H(p,q) = H(p) + KL(p‖q)
```

**原理（源编码定理）**：编码 $X$ 平均至少需 $H(X)$ 比特（无损）。这是**硬下界**：任何「压缩」都不可能低于被保留信息的熵。

**推论（本仓库）**：

> `context/contextCompactor.ts` 与 `deterministicCompressor.ts` 做的是「**在给定预算下最大化保留的互信息**」问题，不是「尽可能短」问题。
> 正确的目标函数是：最大化 $I(\text{保留内容}; \text{任务})$ 受约束于 token 预算 $B$。
> **可证伪检验**：把「保留下来的内容」与「任务所需信息」做互信息代理估计（可用现成的 BM25 命中率/召回率），若压缩后互信息代理下降而 token 下降同比例，说明压缩只是**等比例丢信息**，没有「智能压缩」，不构成能力优势。**这正是 `U3_CONTEXT_RECALL_EXPERIMENT` 该补的度量**。

### 1.2 从熵到「注意力配额分配」

**最大熵原理（Jaynes）**：在满足已知约束的前提下，**熵最大的分布**是无偏的先验。

**推论（本仓库，原创）**：`UNITY_FRAMEWORK_UCE` 的「认知能量 C = 注意力配额 + 信用」目前在工程上没有分配律。可用的严格形式是：

> **在「总额度」与「每任务最低保障」两个约束下，最大化对任务集合的覆盖熵** —— 得到「额度 ∝ 任务不确定度」的分配，而不是平均分配。
> 这与 02 卷「推理强度任务自适应」（EFE 视角）是**同一数学的不同表述**。落地即一个受约束优化：解是解析的（拉格朗日乘子法），无需数值迭代。

## 2. 变分自由能：感知、行动、学习的**同一个**目标函数

### 2.1 变分自由能（VFE）

```
F(q) = E_q[ ln q(s) − ln p(s,o) ]
     = KL( q(s) ‖ p(s|o) )  −  ln p(o)
     ⏟ 复杂度(Complexity)        ⏟ 准确度(Accuracy) 的负
     = KL( q(s) ‖ p(s) )  −  E_q[ ln p(o|s) ]
```

- 因为 $\mathrm{KL}\ge 0$，有 $F \ge -\ln p(o)$：**F 是「惊奇」的上界**（这就是「自由能是 surprise 的可行代理」的由来）。
- 最小化 $F$ 同时做两件事：**降低复杂度**（让后验贴近先验，即「别乱改信念」）与**提高准确度**（让信念解释观测）。
- 这就是 ELBO 的取负：$\ln p(o) \ge -F$。

### 2.2 期望自由能（EFE）：行动的目标

```
G(π) = Risk + Ambiguity
     = KL( q(o_τ|π) ‖ p(o_τ) )                    # 风险：偏离偏好
     + E_{q(s_τ)}[ H( p(o_τ|s_τ) ) ]              # 歧义：观测的不确定性

等价于（负的）两项价值：
G(π) = − EpistemicValue(信息增益) − PragmaticValue(目标效用)
```

**这条对本仓库是最有理论回报的一条**：

- 「探索 vs 利用」不再是经验权衡，而是 $G$ 的**两个加性项**——所以可以**分别加旋钮**（探索旋钮 = 信息增益权重，利用旋钮 = 目标先验 $p(o)$ 的形状）。
- **测试时计算 = 变分策略优化**：搜索/分支/辩论 = 在策略空间下降 $G$（源：Hashash et al. 2026，见 02 卷 §4）。这给「推理强度」提供了理论上界分析：**算力买到的不是「更聪明」，而是「更小的后验歧义」**——因此**当任务本身歧义低时，加算力收益趋零**。
- **可操作判据（推论）**：`reasoning_effort` 的提升应以「歧义是否真的下降」为准——若某个任务加大 effort 后输出分布的熵没有变化，说明算力白烧了。**这条可以直接做成仪表**（用现有 `token-meter` + 输出熵估计）。

### 2.3 与本仓库既有实现的对接

| 理论对象              | 既有实现                               | 差距                                        |
| --------------------- | -------------------------------------- | ------------------------------------------- |
| 复杂度项 = 更新代价   | `genesis/ledger.ts` 的「记录必须结算」 | 会计不变量 ≠ 物理守恒（见 20 卷 §9）        |
| 熵作为派生量          | `genesis/regime.ts` 的模态香农熵       | 已有；但只用于触发 fuse/prune，未做预算分配 |

| EFE 的探索/利用两旋钮 | `context/recallKnobs.ts`（静态）       | 应改为自适应（见 02 卷 L2）                 |

## 3. 贝叶斯滤波与序贯蒙特卡洛（SMC）

### 3.1 递推与粒子近似

```
贝叶斯滤波:  p(s_t | o_{1:t}) ∝ p(o_t | s_t) ∫ p(s_t | s_{t-1}) p(s_{t-1} | o_{1:t-1}) ds_{t-1}

粒子近似:    p̂(s_t) = Σ_i w_t^{(i)} δ(s_t − s_t^{(i)})
重要性权重:  w_t^{(i)} ∝ w_{t-1}^{(i)} · p(o_t | s_t^{(i)}) p(s_t^{(i)} | s_{t-1}^{(i)}) / q(s_t^{(i)} | …)
有效样本数:  ESS = 1 / Σ_i (w̃_t^{(i)})²
```

**可证性质**：$N$ 个粒子的蒙特卡洛误差 ~ $O(1/\sqrt{N})$（与维度无关，但与「粒子枯竭」强相关）。**重采样阈值**通常取 $\mathrm{ESS} < N/2$。

> **对本仓库的意义（`adapters/belief/particleFilterBelief.ts`）**：这是本仓库少见的**L2 级（动力学同构）**实现。要升到 L3 需要证明/测试三件事：
> ① **ESS 监控与重采样触发**是否有？（无则必然粒子枯竭）
> ② **权重归一化与数值稳定**（对数域？）是否有单测？
> ③ **信念收敛性**：给定合成观测序列，后验是否收敛到真值（可用单测机械断言）？
> 三条补齐后，这个适配器就从「有粒子的启发式」变成「有定理支撑的估计器」——**这是把 L2 升到 L3 的典型样本**。

### 3.2 自然梯度（信息几何的入口）

```
普通梯度:   θ ← θ − η ∇F(θ)
自然梯度:   θ ← θ − η F_ij^{-1} ∇_j F(θ)
Fisher 信息: F_ij(θ) = E[ ∂_i ln p(x|θ) ∂_j ln p(x|θ) ]
```

**性质**：自然梯度是**参数化无关**的（重参数化下不变），收敛通常更快、更稳。

> **对本仓库的意义（`adapters/belief/naturalGradientBelief.ts`）**：命名与做法对齐。要升到 L3 需处理**Fisher 矩阵的病态与求逆成本**（通常用对角/块对角近似或共轭梯度求解 $Fv=b$，而非显式求逆）。**注意**：若实现里其实是「普通梯度 + 缩放」，那应诚实降级为 L1。**这是待复核项**（已列入 `TECH_DIRECTION_SYNTHESIS` 的诚实清单）。

## 4. 优化与收敛：把「感觉会收敛」变成「知道会收敛」

### 4.1 随机近似（Robbins–Monro）

```
θ_{n+1} = θ_n + η_n ( y_n − θ_n ),   Σ η_n = ∞,  Σ η_n² < ∞  ⇒  θ_n → θ*  a.s.
```

**要点**：**步长必须满足「调和级数发散、平方可和」**（如 $\eta_n = 1/n$）。常见错误是**常数步长**——那样只收敛到邻域，不收敛到点。

> **对本仓库的检验点**：所有「线上学习/自适应」的地方（记忆权重、检索旋钮）若用固定步长，就应当声明「收敛到邻域，非收敛到最优点」——否则是过度声明。

### 4.2 模拟退火的接受律（与 Arrhenius 同构）

```
Metropolis 接受:  A(ΔE) = min(1, exp(−ΔE / T))
对数冷却:         T_k = T_0 / ln(1+k)
几何冷却:         T_k = α^k ,   α ∈ (0.8, 0.99)
```

**可证性质**：在**对数冷却**与**充分长游走**下，马尔可夫链依分布收敛到**全局最优集**；几何冷却只保证近似。

> **对本仓库的意义（`adapters/memory/heatEquationAnnealer.ts`）**：冷却调度若用几何冷却，则**不得声称「必达全局最优」**；只能声称「良好近似」。这条已在文档里需要显式化（避免过度声明）。与 40 卷 §1 的 Arrhenius 同构是同一枚硬币。

### 4.3 单调收缩 ⇒ 不动点（本仓库的 L3 样板）

```
若 f: X → X 且 d(f(x), f(y)) ≤ c · d(x, y),  c < 1
则 f 有唯一不动点 x*，且任意迭代收敛到 x*（Banach 不动点定理）
```

`genesis/regime.ts` 的论证是本仓库最好的理论兑现：`fuse`（模态数 ≥3 → 严格减）与 `prune`（成本压力 >0.7 → 严格减）**只减不增**，且模态数有下界（≥1），因此**有限步到达不动点**，此后 `plan` 退化为恒等。

> **这是 L3**（有单测）。**推论**：这是全库唯一「可声称数学保证」的地方，应作为其它引擎的**对标模板**：想升级成熟度，就照这个结构补「单调性 + 下界 + 不动点测试」。

### 4.4 凸性与 KKT（何时能说「最优」）

```
min f(x)  s.t.  g_i(x) ≤ 0,  h_j(x) = 0
KKT:  ∇f + Σ μ_i ∇g_i + Σ λ_j ∇h_j = 0,  μ_i ≥ 0,  μ_i g_i = 0
```

只有**凸问题**时 KKT 才既是必要也充分。**推论**：本仓库在做「预算分配/策略选择」时，若把目标写成凸形式（如线性约束下的熵最大化、UCB 的线性置信上界），就能声称最优；否则只能说启发式。**这是一个「顺手拿理论背书」的低成本杠杆**。

## 5. 谱方法：低秩、图谱与幂迭代

### 5.1 SVD 与最优低秩逼近

```
A = U Σ Vᵀ,   σ_1 ≥ σ_2 ≥ … ≥ 0
Eckart–Young:  min_{rank(B) ≤ k} ‖A − B‖_F  =  ‖A − A_k‖_F,  A_k = Σ_{i≤k} σ_i u_i v_iᵀ
```

**性质**：截断 SVD 是**Frobenius 范数下的最优** $k$ 秩逼近（这是定理，不是经验）。

> **对本仓库的意义（`context/lsaEngine.ts`）**：实现是对的（LSA = 截断 SVD）。**但本仓库 `U3_CONTEXT_RECALL_EXPERIMENT` 实测「LSA/SVD 叠加后有害」**（符号精确率 25.5% → 10.5%）。
> **理论解释（推论，本馆原创）**：Eckart–Young 保证的是**在 L2 重构意义下**最优；而检索要的是**排序保序性**，两者不等价。截断会**抹掉低频但判别性极强的方向**（稀有符号恰好是长尾），于是排序变差。
> **这就是「最优重构 ≠ 最优检索」的教科书式反例**，值得把这次实测写成一条**通用教训**：**不要用「重构误差最小」为自己的检索方案背书。**
> 落地：LSA 应保留为**可选**且默认关闭（现状符合），并在文档中记录这次负结果。

### 5.2 PageRank 与幂迭代

```
r = α P r + (1−α) v,    α ≈ 0.85,  ‖r‖_1 = 1
幂迭代:  r_{k+1} = α P r_k + (1−α) v,   ρ(αP) = α < 1  ⇒ 线性收敛
```

**Perron–Frobenius** 保证（在合理条件下）主特征向量唯一且正。

> **对本仓库的意义（`context/codeReferenceGraph.ts`）**：本仓库实测「44 万边引用图 PageRank **零增益**」。
> **理论解释（2026-09-12 已更正——原句方向写反）**：幂迭代的收敛速度取决于**谱隙** $1-alphalambda_2$。
> 谱隙**大**（$lambda_2$ 小）⇒ 混合**快**，数轮即达稳态；若度分布又近规则，稳态就近均匀 ⇒ 排序无判别力。
> 谱隙**小**（$lambda_2 	o lambda_1$）意味着存在**瓶颈**，游走被困在局部、迭代内混合不完。
> 原句「图接近规则/稠密时 $lambda_2 	o lambda_1$」是错的：稠密图的 $lambda_2$ 反而**小**（约 $O(1/sqrt{d})$）。
> **且本仓库的图排序失败根本不是这个机理**——见下方「实测证伪」。
> **方向更正（2026-09-12，原表述写反且已被实测证伪）**：混合时间 ~ 1/谱隙。
> 谱隙**大**（λ₂ 小）⇒ 混合**快** ⇒ 迅速收敛到稳态；若度分布又近规则（Gini→0），稳态就近均匀 ⇒ 排序无判别力。
> 谱隙**小**（λ₂→1）意味着存在**瓶颈**，游走被困在局部，稳态**不均匀**但迭代内混不完。
> 原句「稠密 ⇒ λ₂→λ₁」是错的：稠密图的 λ₂ 反而**小**（~O(1/√d)）。
>
> **实测证伪（`evals/rank-veto-retro.mjs`，33 条真实查询）**：本仓库稠密图实测谱隙 **0.266**、
> 稳态 KL **0.522**、有效支撑率 **0.593**、度 Gini **0.482**——**分布远非均匀**，该族判据一条都没触发，
> 而该路已知 **−6.1pp**。故「谱隙/均匀性」**不能**解释本仓库的图排序失败。
>
> **真机理（同一次实测挖出）**：图排序对**查询不敏感**——Top-14 跨查询平均重合度 **0.936**，BM25 仅 **0.058**；
> 枢纽文件在 33/33 查询中全部出现。它不是「退化」，而是**常量偏置**。
>
> **现行可操作判据（已回溯验证 3/3）**：量候选路由在各查询 Top-K 之间的**平均两两 Jaccard**（无需标注数据）；
> ≥0.5 即否决。实现见 `src/context/rankVeto/index.ts`。

### 5.3 图 Laplacian 与 Dirichlet 能量

```
L = D − A  (组合 Laplacian)
Dirichlet 能量:  E(x) = ½ Σ_{(i,j)∈E} w_ij (x_i − x_j)² = xᵀ L x
平滑/扩散:       x_{k+1} = x_k − η L x_k = (I − η L) x_k
```

这就是 `heatEquationAnnealer` 的**图版本**（连续情形即热方程 $\partial_t u = D\nabla^2 u$）。**过平滑**现象：反复应用 $I-\eta L$ 会让所有 $x_i$ 趋于常数——**这正是 GNN 的 oversmoothing 与上条 PageRank 均匀化是同一个数学**。

> **推论**：本仓库的「共振/扩散」类算子在**迭代步数上必须有界**，否则必然过平滑到无信息。这是需要显式声明的**硬约束**（`prefixStability.ts` 可能已在做类似守卫，待核）。

## 6. 动力系统：稳定性、分岔、耗散

```
不动点:        f(x*) = 0
线性稳定性:    δx' = J(x*) δx,   Re(eig(J)) < 0 ⇒ 渐近稳定
Hopf 分岔:     一对共轭特征值穿越虚轴  ⇒ 极限环（自激振荡）
Lyapunov:      V(x) > 0,  V̇(x) < 0  ⇒ 渐近稳定（可作证书）
耗散:          ∇·f < 0  ⇒ 相空间体积收缩 ⇒ 存在吸引子
```

**与本仓库的对应**：

- **Hopf 分岔 = 振荡**：`evolution`/`spark` 的周期性发射若出现自激振荡，未必是 bug，可能是**动力学必然**；判据是「是否出现一对共轭特征值穿越虚轴」。40 卷的 Brusselator/Oregonator 振荡是同源。
- **Lyapunov 函数 = 可证收敛的证书**：`regime.ts` 的「模态数」就是一个离散 Lyapunov 函数（单调递减且有下界）——这给了一个**通用配方**：想证明收敛，就找一个有下界的单调量。
- **耗散 = 吸引子存在**：见 20 卷 §2（OmniHarness 是**开放耗散系统**）。

## 7. 集中不等式：给评估以**置信区间**

```
Hoeffding:   P( |X̄ − E[X]| ≥ t ) ≤ 2 exp(−2n t² / (b−a)²)
Chernoff:    P( X ≥ (1+δ)μ ) ≤ exp(−μδ²/3)
```

> **对本仓库的意义（`eval/passK.ts`）**：**Pass@k 报点估计是不够的**。当前 `--min-pass-k 3,0.9` 是**点阈值门禁**，没有置信区间，因此**小样本下会随机红/绿**。
> **建议（低成本高价值）**：把门禁改为「**下置信界** ≥ 阈值」，例如用 Hoeffding 或 Wilson 区间；这样「50 采样、Pass@1=1.0」才能被正确表述为「$p \ge 1-\epsilon$ 有 95% 置信」。这是 01 卷「eval 严谨性」在数学上的落点。

## 8. 组合与调度：DAG 的代价

```
Kahn 拓扑排序:  O(V + E)
关键路径 = 最长路径（DAG 上可线性 DP）
并行下界（Amdahl）:  加速比 S = 1 / ( (1−p) + p/N )
```

> **对本仓库的意义（`autonomy/workflowRunner.ts`，并发上限 4）**：Amdahl 说明**并发上限的收益递减**；因此「提高并发数」在不改依赖图时收益有限，**真正的杠杆是缩短关键路径**（拆分长依赖链）。这给「Workflow DAG 优化」一个明确方向：不是加线程，而是**改图**。
