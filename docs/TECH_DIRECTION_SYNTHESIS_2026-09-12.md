# OmniHarness 总体技术方向（2026-09-12）

> 性质：**在现有基础上升级的总体方向**，不是重写方案，不是功能清单。
> 来源：`docs/library/` 九卷（前沿 3 卷 + 学科 5 卷 + 索引）+ 本仓库代码实测 + 既有 `UCE` / `UPGRADE_PLAN_SYNTHESIS` / `REFACTOR_BOARD`。
> 立场：**不新增隐喻引擎**；只做三件事——**把已有的隐喻升格为机制**、**把已有的能力补上度量**、**把缺失的那根理论柱子补上**。

---

## 0. 一句话与三句话

**一句话**：OmniHarness 的最终形态是「**受约束的耗散推理系统**」——靠持续耗散资源维持一个低熵、可审计、可验证、可自演化的推理秩序。

**三句话**：
1. **定位**：2026 的竞争维度已从「模型能力」转为「Harness 质量」（`library/01`）。本仓库天生就在这个层级，**不该去拼积木丰富度，该拼可靠执行的默认架构**。
2. **缺口**：本仓库实测的所有负结果（LSA 有害、PageRank 零增益、频域共振无效）**根因是同一个——度量错配**（`library/10` §5、`library/11` §9）。这是全项目最被低估的系统性缺口。
3. **方向**：因此升级的**主轴不是加能力，而是「换到正确的数学空间上去做同一件事」**——这同时解释了过去的失败，也给出了下一步。

## 1. 核心命题：四公理（在 UCE 三公理上补第四根）

UCE 已立三公理。本方向**补一条**，并给出每条的可检验形式：

| # | 公理 | 形式化（`library/11` §9） | 可检验性 | 现状 |
|---|---|---|---|---|
| Ⅰ | **归一** | 表示构成 **copresheaf**；「无后遗症」⇔ 满足**局部性 + 粘合**公理 | 构造「局部一致但全局不同」的配置，看系统是否消解 | 部分（`genesis` 代数已 L3，全局表示未证） |
| Ⅱ | **守恒** | **记账不变量**：record/commit 闭合（**非物理守恒，措辞须修正**，`library/20` §9） | 已可机械检出遗漏 | **L3**（`ledger`） |
| Ⅲ | **演变** | 保序映射下**适应度爬山 + 退火**；用 **Lyapunov 单调量**证明收敛 | `library/10` §4.3 的三步配方 | **L3**（仅 `regime`） |
| **Ⅳ** | **度量**（新增） | 优化/检索/匹配必须在**正确几何**上：Fisher–Rao / **层 Laplacian** /（窄域）最优传输 | 换度量后召回是否提升（**同 corpus 开关隔离**） | **缺失**——全部负结果的共同根因 |

> **为什么第四公理是必须的（本方向的核心论断）**：
> 三公理解决了「表示统一 / 账目清楚 / 机制自适应」，但**没回答「在哪个空间里比较相似」**。
> 而本仓库所有实测负结果**全是度量错配**：
> - LSA：Eckart–Young 保证的是 **L2 重构最优**，检索要的是**排序保序**——两者不等价，截断抹掉了长尾判别方向；
> - PageRank：**谱隙→0 时幂迭代收敛到均匀分布**，相对排序不变且白增 token（且代码图天然异配，单一标量分数不适用）；
> - 频域共振：与词袋在短符号域**高度冗余**；
> - 余弦相似度：**假设统计流形平坦**，只在近似成立时才有效。
> **把「度量」立为公理后，这些失败从「玄学失效」变成「可解释、可修正的度量错误」**——这是本次调研对项目最大的认知增量。
> **并且它给出一个统一的升级杠杆**：不是「加一个检索器」，而是「换一个度量」。

## 2. 七条升级主线（T0–T6）

> 与既有看板交叉：`RB` = `REFACTOR_BOARD_2026-09-12` 的 P 编号；`UB` = `UPGRADE_BOARD` 的 U 编号。
> 「可证伪验收」一列是**唯一的完成判据**；跑不出数字不得声称完成。

### T0 · 成熟度治理（**跨切，建议最先做**）

| 项 | 内容 |
|---|---|
| 理论来源 | `library/README` 的铁律二（L0–L3 分级） |
| 现状 | 14 个隐喻引擎无成熟度标注，文档易过度声明（如「能量守恒」「量子纠错」） |
| 动作 | ① 在 `CODE_STANDARD.md` 增一节「隐喻引擎成熟度声明」；② 每个隐喻引擎必须**声明等级 + 给出对应测试**；③ 措辞修正：`ledger` 称「记账不变量」、`qec` 去量子化定义 |

### T1 · 表示归一（层论）

| 项 | 内容 |
|---|---|
| 理论来源 | `library/11` §4（细胞层、粘合公理）、§3.2（左 Kan 扩张）；`library/09`(README §4 映射) |
| 现状 | core↔adapters 双向依赖 17 处（`RB` P1）；`liftOperator` 是否保组合律**未证** |

| 可证伪验收 | ① 组合律测试全绿；② `core→adapters` = 0；③ 每次重构产出**迁移映射表 + 残差清单**（残差 = 0 才算无缝） |
| 依赖 | 与 `RB` P1 同源，可合并推进 |

### T2 · 度量升级（信息几何）——**本方向的差异化核心**

| 项 | 内容 |
|---|---|
| 理论来源 | `library/10` §5、`library/11` §4.3/§6/§7 |
| 现状 | 检索 = BM25 + 形态归并（实测召回 **67.0%**，符号精度 25.5%）；余弦/内积/标量分数为主要度量 |
| 动作 | ① **层化 repo-map**：把「节点→边」的翻译**显式化**（节点在边上的坐标 = 调用深度/参数数/跨模块性；被调方 = 被调频次/导出性/有无测试），做**层一致性聚合**，替代单一标量排序；② **前置否决检查**：图排序前先测**谱隙与度分布**，谱隙过小直接否决（省掉无效实验）；③ （窄域）在 Top-50→Top-10 **重排**上用**切片 Wasserstein / Sinkhorn**；④ 检索策略 **UCB bandit 化**（MemCon 式，`library/02` §2） |
| 可证伪验收 | 在**同一 corpus、同一开关隔离**下：召回 **67.0% → ≥75%** 且 token 增幅 ≤1.5×；**若层化后与 BM25 的簇高度重合 ⇒ 判定无效并放弃**（这是预先承诺的失败判据） |
| 依赖 | 无（纯本地、零依赖可实现）；但需 `evals/context-efficiency` 扩展为「可换度量」的对照框架 |
| 诚实边界 | 语义鸿沟的残余（`policy` vs `execPolicy`）**不承诺**由度量解决；本主线承诺的是**结构性错配**的修正 |

### T3 · 记忆生命周期与时间（生物 + 化学）

| 项 | 内容 |
|---|---|
| 理论来源 | `library/02` §2.1（Ghost Memory）、`library/30` §6（自创生闭合）、`library/40` §3（耗散自组装四步循环） |
| 现状 | 记忆 = 纯相关性检索，**无时间维度**；`memoryAnnealing` 端口存在但成长性实现缺位（L0）。**重构期文件移动会让旧事实压过新事实** |
| 动作 | ① 记忆条目带**写入时间 + 失效条件**；检索分数 = 相关性 × **时间衰减** × **冲突消解（新胜旧）**；② 实现「**充能 / 衰减 / 解离**」循环（对齐耗散自组装）；③ 记忆五层对齐（`library/01` §3）：补齐 **scratchpad（便签）+ 「重置点 + 交接物」**，而不是让 repo-map 常驻（**这与 `UPGRADE_PLAN_SYNTHESIS` U2/U3 的「持续注入」有张力，建议改为此方案**） |
| 可证伪验收 | 构造「文件移动」语料（`library/02` §7 L1）：旧事实不再压过新事实；且**上下文重置后能靠便签恢复任务**（构造中断-恢复用例） |
| 依赖 | 受益于栈升级 T6（Node 26 的 Temporal 默认启用，时间处理零依赖） |
| 诚实边界 | 「遗忘」是有代价的：**必须先定义哪些事实不可遗忘**（存续约束，见 `library/30` §4），否则会误删关键记忆 |

### T4 · 验证闭环（Harness Engineering）

| 项 | 内容 |
|---|---|
| 理论来源 | `library/01` §2/§6/§8；`library/20` §8（syndrome 校验）；`library/40` §6（双稳态 = 二元 verdict） |
| 现状 | 有门禁链 fail-closed、审计链、hooks 兼容层；**缺**：自验证清单、反漂移、失败挖掘、agent 读自己 trace |
| 动作 | ① **自验证循环**（H1，`library/01` §8）；② **反漂移检测**（H2）；③ **失败模式自动挖掘**（H3，Self-Harness 式，落 `twistDiscoveryEngine`）；④ **工具描述即不可信输入**（H4，落 `promptInjectionGuard` + `mcpToolMapper`）；⑤ **agent 只读自省 trace**（H5）；⑥ **eval 与生成路径隔离**（agent 自评系统性偏高）；⑦ **Pass@k 门禁改为「下置信界 ≥ 阈值」**（`library/10` §7） |
| 可证伪验收 | ① 构造「假完成」用例被抓出且成功率不降；② 循环编辑用例可告警；③ 一轮失败挖掘产出 ≥1 条被回归门禁采纳的改进；④ 小样本下门禁不再随机红/绿（重复 20 次跑，结果稳定） |
| 依赖 | T0（需要有等级声明才能说「验证了什么」） |
| 诚实边界 | ④ 需要先接入 `AgentDojo`/`InjecAgent` 子集，否则只是「有净化」而非「有度量」 |

### T5 · 训练信号（RLVR）——把 L1 提到 L3

| 项 | 内容 |
|---|---|
| 理论来源 | `library/01` §2（LangChain/Vercel 实证）、`library/02` §1/§3/§4、`library/30` §1（多样性抗 Echo Trap） |
| 现状 | `evolution/` 结构齐全（含 `failClosedEvolutionGate`，比多数实现谨慎），但：势函数**覆盖率未知**、Echo Trap 防护**未证**、RAGEN 明载会训崩 |
| 动作 | ① **势函数覆盖率体检**：清点多少任务步骤真有 verifiable verdict（编译/测试/类型检查）；**若覆盖率过低，应诚实降级表述为「局部可验证」**；② **多样性保留**作为抗 Echo Trap 第一道防线（不需要梯度稳定，先要多样性）；③ **允许小概率接受劣解**（退火化：(1+1)-EA → 退火，是**免费增益**，`library/30` §1.2）；④ **技能稀疏化**（SkillsBench 实证：人工精编 +16.2pp，**AI 自生成无正增益**，堆叠引噪声 ⇒ 单一职责 + 选择上界 + 渐进披露）；⑤ **推理强度任务自适应**（EFE 视角，`library/02` §4） |
| 可证伪验收 | ① 覆盖率报告出数；② 同 corpus 开关隔离下，连续 N 轮适应度曲线改善 ≥10% 且**多样性不塌缩**；③ 技能堆叠用例的上下文噪声下降；④ 难/易分层后总 token 下降或持平而成功率不降 |
| 依赖 | T0（等级声明）、T4（verdict 采集） |
| 诚实边界 | **不承诺「训出更强模型」**——本仓库不训模型；本主线只做**策略层**的自改进。「Echo Trap」是已知坑，未验证前不得声称「自主进化」 |

## 3. 明确不做（反泡沫清单）

| 不做 | 理由 |
|---|---|
| 引入向量数据库 / tree-sitter / 外部图数据库 | 违零依赖铁律；且本仓库实测证明「换度量」比「换存储」更根本（T2） |
| 引入 microVM / 容器运行时 | 违零依赖；现有沙箱矩阵方向正确 |
| GPU 上的 RL 训练 | 本仓库不训模型（T5 边界）；分布式训练系统（ROLLART 等）不适用 |
| 量子硬件 / 真实的 QEC 实现 | `qec` 应去量子化定义为「校验关系 + 冗余」（`library/20` §8） |
| 真实化学/生物湿实验 | `library/40` §7 |
| 新增更多物理/生物隐喻引擎 | 违「苦涩教训」（`library/01` §7）：Harness 必须轻量、可丢弃；**先把现有 14 个升格** |
| 把反应-扩散/图灵斑图用于目录分区 | 需要标定语义参数，**重构期不引入**（`library/40` §5，列为远期观察） |
| 用 Landauer 极限论证「省电」 | 实测比极限高 8–9 个数量级，引用即为滥用（`library/20` §3） |
| 把「认知能量守恒」称作物理解 | 它是**记账不变量**（可被违反的断言），不是定律（`library/20` §9） |
| 引用脑效率（20W）为软件性能背书 | 本仓库不控制硬件（`library/30` §7） |

## 6. 诚实清单（不诓骗）

**A. 外部数字均为自报，未独立复现**：
- 上海 AI Lab Self-Harness「Terminal-Bench-2.0 +104%」、ROLLART「1.35–2.05× 加速」、AgeMem/MemCon 的 pp 提升、ARC-AGI-3「98.98% RHAE」、TS 7 的 10×/11.9× 等——**均为厂商/社区自报**。其中 ARC-AGI-3 结果**已公开被质疑**（依赖固定兜底规则、未经官方团队独立验证）。
- 本方向**不引用这些数字作为本项目的目标或背书**，只作为「方向存在」的证据。

**B. 本项目自身的实测负结果与真实基线**（这才是可引用的）：
- 文件召回 **67.0%**、符号精度 **25.5%**（`evals/context-efficiency`，**实测**）；
- LSA 叠加后符号精度 25.5%→10.5%、PageRank 零增益、频域共振零增益、PRF 有害（`docs/U3_CONTEXT_RECALL_EXPERIMENT.md`，**实测**）；
- 单测基线 1127（`UPGRADE_BOARD_2026-09-12`）；
- `check --strict` 阻断 13 → 3（P0.1 后，**实测**）。

**C. 本方向中属于「推论 / 判断」而非「来源结论」的部分**（已逐条标注「推论」）：
- 第四公理「度量」的提出；
- 「LSA/PageRank 失败的根因是度量错配」的解释；
- 「谱隙前置否决检查」；
- 「层化 repo-map」的具体构造；
- 「介质 + 调制 = 计算」与 harness 的结构同构论断；
- 「技能/工具网络是否构成超循环」的检验方法。

**D. 待复核项（本方向自己也不知道的）**：
1. `naturalGradientBelief` 是真自然梯度还是「普通梯度 + 缩放」→ 若是后者应降级 L1；
2. `liftOperator` 是否真保组合律（T1 的组合律测试就是为了回答这个）；
3. 巨型函数门禁实测 2 处 vs 子代理启发式报 7 处，口径不一致（`REFACTOR_BOARD` P4.5 已记）；
4. 「认知能量 C」目前**没有分配律**，只有记账（`library/10` §1.2 给出了一个可实现的分配方案，但未验证）。

**E. 措辞修正（本方向要求立即生效）**：
- 「认知能量守恒律」→「**账本闭合不变量**」（`library/20` §9）；
- 「量子纠错」→「**轨迹级校验关系 + 显式冗余**」（`library/20` §8）；
- 所有 `joules` 数值必须保留「**经验系数估算代理值，非实测物理量**」的标注（`library/20` §3）。
