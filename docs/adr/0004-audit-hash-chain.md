# 0004 审计日志 SHA256 哈希链（非快照摘要）

- 日期：2026-09-06
- 状态：已接受

## 背景

合规场景要求审计日志**不可篡改可验证**。简单的「快照摘要」（只存整份日志的哈希）无法区分
「改了一条内容」「删了一条」「插了一条」三种篡改，且重组后摘要仍可能巧合一致。

## 决策

审计日志采用链式哈希：`h_n = SHA256(prev ‖ canonical(e_n))`，每条记录携带 `seq / prev / hash`。
提供 `verify()` 三重篡改检出：改内容、删条目、插条目均能被检出；跨进程重启经 `resumeChain()` 续链。
旧格式日志（无链）判 `ok:null`（标记为「不可验证」而非「已篡改」，避免误报）。

## 后果

- 正面：达到合规级不可篡改可验证；合规导出 `buildComplianceReport` 暴露 `summary.chain`，
  CLI `audit export --compliance` 仅在链确凿断裂（`ok:false`）时告警退出。
- 负面：每条记录体积略增；序列化需 canonical 稳定（key 顺序固定）。
- 替代方案：纯摘要（检出力不足，否决）/ 中心化签名服务（引入外部依赖，否决）。
