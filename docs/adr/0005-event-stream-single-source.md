# 0005 事件流为唯一真相源（投影出模型消息）

- 日期：2026-09-06
- 状态：已接受

## 背景

Agent 运行产生大量异构状态（用户消息、工具调用、模型回复、检查点）。若每类状态各自存储，
会出现不一致、难以回放、难以审计的问题。

## 决策

以 `SessionEvent` 事件流为**唯一真相源**：所有中间状态都是事件流的一次投影。

- 模型上下文（messages）由事件流投影得到；
- `checkpoint` 通过快照事件流（及可选文件快照）实现回滚；
- 重放事件流即可完整重建任意时刻状态。

## 后果

- 正面：可回放、可审计、可断点续跑；检查点回滚只需还原事件流。
- 负面：投影层需谨慎保证确定性（同输入同输出）；事件 schema 演进需向后兼容。
- 替代方案：多源存储（易不一致，否决）。
